Exam 1

  1. Question

    La gráfica presenta las exportaciones en millones de dólares de determinados productos del sector alimentario en Ecuador, Venezuela, Estados Unidos y resto del mundo entre los años 2018 y 2020.

    Otra representación que muestra toda la información de la gráfica anterior es:



    Solution

    La respuesta correcta es la opción C (gráfica de líneas).

    Para determinar cuál representación muestra toda la información de la gráfica original, debemos analizar qué tipo de representación permite:

    1. Visualizar todos los años (2018, 2019, 2020)
    2. Comparar todos los países/regiones simultáneamente
    3. Observar la evolución temporal de las exportaciones
    4. Identificar tendencias de crecimiento o decrecimiento

    Análisis de cada opción:

    Opción A (Python - Barras horizontales): Muestra solo datos de un año específico, no permite ver la evolución temporal completa

    Opción B (R - Gráfica circular): La representación circular no facilita la comparación de evolución temporal entre países

    Opción C (TikZ - Gráfica de líneas): Permite ver claramente la evolución temporal de todos los países y comparar tendencias

    Opción D (Python - Barras verticales): Muestra solo datos de un año intermedio, información incompleta para análisis temporal

    La competencia de Interpretación y Representación requiere identificar representaciones equivalentes que preserven toda la información y faciliten el análisis comparativo temporal.


    1. Falso. La representación circular no facilita la comparación de evolución temporal entre países
    2. Falso. Muestra solo datos de un año específico, no permite ver la evolución temporal completa
    3. Falso. Muestra solo datos de un año intermedio, información incompleta para análisis temporal
    4. Verdadero. Permite ver claramente la evolución temporal de todos los países y comparar tendencias
