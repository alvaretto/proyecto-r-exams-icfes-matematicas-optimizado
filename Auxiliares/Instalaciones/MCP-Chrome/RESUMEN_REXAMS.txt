┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚀 FLUJO DE TRABAJO COMPLETO                                                │
└──────────────────────────────────────────────────────────────────────────────┘

  PASO 1: Generar examen en R
  ────────────────────────────────────────────────────────────────────────────
  R> library(exams)
  R> exams2html("mi_examen.Rmd", dir="out_html_cloze")

  PASO 2: Ejecutar verificador
  ────────────────────────────────────────────────────────────────────────────
  $ cd Auxiliares/Instalaciones/MCP-Chrome
  $ ./verificar_examen.sh

  PASO 3: Seleccionar examen
  ────────────────────────────────────────────────────────────────────────────
  El script lista todos los exámenes HTML disponibles
  Selecciona el número del examen que quieres verificar

  PASO 4: Elegir tipo de verificación
  ────────────────────────────────────────────────────────────────────────────
  1) Verificación Básica      - Rápida, errores y screenshot
  2) Análisis Completo        - Detallada, todo incluido
  3) Verificación Responsive  - Múltiples dispositivos
  4) Verificación MathJax     - Fórmulas matemáticas
  5) Metadatos ICFES          - Competencias y niveles
  6) TODOS los prompts        - Genera todos a la vez

  PASO 5: Copiar prompt generado
  ────────────────────────────────────────────────────────────────────────────
  El script genera un prompt completo y optimizado
  Copia el texto completo del prompt

  PASO 6: Pegar en Copilot (VS Code Insiders)
  ────────────────────────────────────────────────────────────────────────────
  1. Abre VS Code Insiders
  2. Presiona Ctrl+Shift+I (abre Copilot)
  3. Pega el prompt
  4. Presiona Enter

  PASO 7: Revisar resultados
  ────────────────────────────────────────────────────────────────────────────
  Copilot te mostrará:
  • Errores encontrados (si hay)
  • Screenshots generados
  • Reporte detallado
  • Recomendaciones

  PASO 8: Corregir problemas (si es necesario)
  ────────────────────────────────────────────────────────────────────────────
  1. Edita el archivo .Rmd original
  2. Regenera el examen en R
  3. Vuelve al PASO 2

  Tiempo: ~30 segundos
  Verifica:
    ✓ Errores de JavaScript
    ✓ Imágenes rotas
    ✓ Screenshot general
  
  2. ANÁLISIS COMPLETO (Opción 2) ⭐ RECOMENDADO
  ────────────────────────────────────────────────────────────────────────────
  Cuándo usar: Antes de publicar un examen
  Tiempo: ~2 minutos
  Verifica:
    ✓ Errores y warnings
    ✓ Todas las imágenes
    ✓ MathJax completo
    ✓ Rendimiento
    ✓ Screenshots detallados
  
  3. VERIFICACIÓN RESPONSIVE (Opción 3)
  ────────────────────────────────────────────────────────────────────────────
  Cuándo usar: Exámenes que se verán en diferentes dispositivos
  Tiempo: ~1 minuto
  Verifica:
    ✓ Vista móvil (375x667)
    ✓ Vista tablet (768x1024)
    ✓ Vista desktop (1920x1080)
  
  4. VERIFICACIÓN MATHJAX (Opción 4)

  Verifica:
    ✓ MathJax cargó
    ✓ Sin errores de renderizado
    ✓ Todas las fórmulas visibles

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🆘 SOLUCIÓN DE PROBLEMAS                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

  PROBLEMA: "No se encontraron exámenes HTML"
  ────────────────────────────────────────────────────────────────────────────
  Solución:
    1. Verifica que existan archivos: ls out_html_cloze/*.html
    2. Genera un examen primero en R
    3. Vuelve a ejecutar ./verificar_examen.sh

  PROBLEMA: "Copilot no reconoce el servidor MCP"
  ────────────────────────────────────────────────────────────────────────────
  Solución:
    1. Ejecuta: ./test_mcp.sh
    2. Reinicia VS Code Insiders: killall code-insiders && code-insiders
    3. Espera 10 segundos y vuelve a intentar

  PROBLEMA: "Las imágenes no cargan"
  ────────────────────────────────────────────────────────────────────────────
  Solución:
    1. Verifica rutas en el HTML
    2. Usa rutas absolutas o relativas correctas
    3. Ejecuta verificación de imágenes específica

  PROBLEMA: "MathJax no renderiza"
  ────────────────────────────────────────────────────────────────────────────
  Solución:
    1. Usa la opción 4 (Verificación MathJax)
    2. Asegúrate de esperar 5 segundos
    3. Verifica que MathJax esté incluido en el HTML
