# Generar tres números para los porcentajes. Su suma siempre debe ser igual a 100
generar_vector_unico <- function() {
  repetir <- TRUE
  while (repetir) {
    # Generar el primer número como un múltiplo de 5 entre 5 y 60.
    # Esto aumenta las posibilidades de tener tres números únicos.
    primer_numero <- sample(seq(5, 60, by = 5), 1)
    
    # Calcular el máximo valor posible para el segundo número,
    # asegurándose de que haya espacio para un tercer número único.
    max_segundo_numero <- 95 - primer_numero
    
    # Generar el segundo número asegurando que sea diferente al primero
    posibles_segundos <- seq(5, max_segundo_numero, by = 5)
    posibles_segundos <- posibles_segundos[posibles_segundos != primer_numero]
    if (length(posibles_segundos) > 0) {
      segundo_numero <- sample(posibles_segundos, 1)
    } else {
      next
    }
    
    # Calcular el tercer número necesario para que la suma sea 100,
    # asegurándose de que sea diferente a los dos anteriores.
    tercer_numero <- 100 - primer_numero - segundo_numero
    
    # Verificar si los tres números son únicos
    if (length(unique(c(primer_numero, segundo_numero, tercer_numero))) == 3) {
      repetir <- FALSE
    }
  }
  
  # Crear el vector
  vector <- c(primer_numero, segundo_numero, tercer_numero)
  
  return(vector)
}

Question

El líder de un programa de adopción de mascotas encuestó a 600 personas para conocer qué animal les interesaría adoptar. Del total de encuestados, el 20% adoptaría un pez, el 45% adoptaría un pato y el 35% adoptaría un canario.

¿Cuál de las siguientes representaciones NO muestra correctamente la información recolectada en la encuesta?

Answerlist





Solution

La representación que NO muestra correctamente la información recolectada en la encuesta es el gráfico de barras verticales.

Análisis de las representaciones:

  • Tabla: Correcta. Aunque muestra números absolutos de personas, estos corresponden correctamente a los porcentajes mencionados en la encuesta.

  • Gráfico de barras verticales: Incorrecto. Aunque la etiqueta del eje Y indica “Porcentaje de personas interesadas en adoptar”, los datos o la correspondencia de animales no coinciden correctamente con la información de la encuesta.

  • Gráfico de barras horizontales: Correcto. Muestra números absolutos de personas que corresponden correctamente a los porcentajes de la encuesta.

  • Gráfico de torta: Correcto. Muestra correctamente la distribución proporcional usando números absolutos que corresponden a los porcentajes mencionados.

Por lo tanto, el gráfico de barras verticales es el único que NO muestra correctamente la información, mientras que las demás opciones SÍ la representan correctamente.
