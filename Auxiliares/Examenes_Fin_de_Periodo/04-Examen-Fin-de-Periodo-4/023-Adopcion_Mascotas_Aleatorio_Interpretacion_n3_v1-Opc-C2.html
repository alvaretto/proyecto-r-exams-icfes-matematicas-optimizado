# Generar tres números para los porcentajes. Su suma siempre debe ser igual a 100
generar_vector_unico <- function() {
  repetir <- TRUE
  while (repetir) {
    # Generar el primer número como un múltiplo de 5 entre 5 y 60.
    # Esto aumenta las posibilidades de tener tres números únicos.
    primer_numero <- sample(seq(5, 60, by = 5), 1)
    
    # Calcular el máximo valor posible para el segundo número,
    # asegurándose de que haya espacio para un tercer número único.
    max_segundo_numero <- 95 - primer_numero
    
    # Generar el segundo número asegurando que sea diferente al primero
    posibles_segundos <- seq(5, max_segundo_numero, by = 5)
    posibles_segundos <- posibles_segundos[posibles_segundos != primer_numero]
    if (length(posibles_segundos) > 0) {
      segundo_numero <- sample(posibles_segundos, 1)
    } else {
      next
    }
    
    # Calcular el tercer número necesario para que la suma sea 100,
    # asegurándose de que sea diferente a los dos anteriores.
    tercer_numero <- 100 - primer_numero - segundo_numero
    
    # Verificar si los tres números son únicos
    if (length(unique(c(primer_numero, segundo_numero, tercer_numero))) == 3) {
      repetir <- FALSE
    }
  }
  
  # Crear el vector
  vector <- c(primer_numero, segundo_numero, tercer_numero)
  
  return(vector)
}

Question

El líder de un programa de adopción de mascotas encuestó a 170 personas para conocer qué animal les interesaría adoptar. Del total de encuestados, el 20% adoptaría una serpiente, el 50% adoptaría una vaca y el 30% adoptaría una araña.

¿Cuál de las siguientes representaciones muestra correctamente la información recolectada en la encuesta?

Answerlist





Solution

La gráfica que representa correctamente la información recolectada en la encuesta es el gráfico de barras horizontales.

Análisis de las representaciones:

• Tabla: Incorrecto. Aunque presenta los porcentajes calculados correctamente, una tabla de datos no constituye una representación gráfica visual que permita interpretar y comparar eficientemente las preferencias de adopción. La pregunta solicita específicamente una “representación” que facilite el análisis visual de la información.

• Gráfico de barras verticales: Incorrecto. Presenta una inconsistencia crítica entre la etiqueta del eje Y que indica “% personas” y los valores numéricos mostrados en las barras, que corresponden a porcentajes sin el símbolo %. Esta discrepancia entre la escala declarada y los datos representados genera confusión en la interpretación de los resultados.

• Gráfico de barras horizontales: Correcto. Esta representación muestra de manera precisa y coherente las cantidades absolutas de personas interesadas en cada tipo de mascota. Los valores numéricos están claramente etiquetados sobre cada barra, el eje X indica correctamente “Cantidad de personas interesadas en adoptar”, y permite una comparación visual directa entre las preferencias, facilitando la toma de decisiones basada en datos cuantitativos.

• Gráfico circular: Incorrecto. Aunque los valores numéricos son correctos, presenta dos errores fundamentales: (1) inconsistencia en las etiquetas que mezclan “Personas interesadas” con “% de Personas interesadas”, creando confusión conceptual entre valores absolutos y relativos; (2) el formato circular, aunque visualmente atractivo, dificulta la comparación precisa de magnitudes similares, especialmente cuando las diferencias entre categorías son pequeñas.
