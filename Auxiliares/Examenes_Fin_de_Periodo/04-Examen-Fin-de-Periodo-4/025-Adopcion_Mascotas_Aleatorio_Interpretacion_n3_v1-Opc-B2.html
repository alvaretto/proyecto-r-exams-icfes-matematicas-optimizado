# Generar tres números para los porcentajes. Su suma siempre debe ser igual a 100
generar_vector_unico <- function() {
  repetir <- TRUE
  while (repetir) {
    # Generar el primer número como un múltiplo de 5 entre 5 y 60.
    # Esto aumenta las posibilidades de tener tres números únicos.
    primer_numero <- sample(seq(5, 60, by = 5), 1)
    
    # Calcular el máximo valor posible para el segundo número,
    # asegurándose de que haya espacio para un tercer número único.
    max_segundo_numero <- 95 - primer_numero
    
    # Generar el segundo número asegurando que sea diferente al primero
    posibles_segundos <- seq(5, max_segundo_numero, by = 5)
    posibles_segundos <- posibles_segundos[posibles_segundos != primer_numero]
    if (length(posibles_segundos) > 0) {
      segundo_numero <- sample(posibles_segundos, 1)
    } else {
      next
    }
    
    # Calcular el tercer número necesario para que la suma sea 100,
    # asegurándose de que sea diferente a los dos anteriores.
    tercer_numero <- 100 - primer_numero - segundo_numero
    
    # Verificar si los tres números son únicos
    if (length(unique(c(primer_numero, segundo_numero, tercer_numero))) == 3) {
      repetir <- FALSE
    }
  }
  
  # Crear el vector
  vector <- c(primer_numero, segundo_numero, tercer_numero)
  
  return(vector)
}

Question

El líder de un programa de adopción de mascotas encuestó a 330 personas para conocer qué animal les interesaría adoptar. Del total de encuestados, el 30% adoptaría un camaleón, el 25% adoptaría un gato y el 45% adoptaría una vaca.

¿Cuál de las siguientes representaciones muestra correctamente la información recolectada en la encuesta?

Answerlist





Solution

El gráfico que representa correctamente la información recolectada en la encuesta es el gráfico de barras verticales.

Análisis de las representaciones:

  • Tabla: Incorrecta. La tabla presenta un error en los datos del segundo animal, mostrando un valor que no corresponde al número real de personas de la encuesta (tiene un error de +10 personas).

  • Gráfico de barras verticales: Correcto. Este gráfico muestra correctamente los porcentajes de personas interesadas en adoptar cada animal, con el eje horizontal representando los tipos de animales y el eje vertical mostrando los porcentajes correspondientes.

  • Gráfico de barras horizontales: Incorrecto. Aunque el formato es válido, los valores mostrados corresponden a números absolutos de personas en lugar de los porcentajes solicitados en la pregunta.

  • Gráfico de torta: Incorrecto. Similar al gráfico de barras horizontales, muestra números absolutos de personas en lugar de los porcentajes solicitados.
