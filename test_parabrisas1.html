    Las dimensiones de un ventana son 15 cm de largo y 12 cm de ancho. Este es un ventana plano y de forma rectangular, correspondiente a de un modelo a escala.

    El ventana cuenta con 2 plantillass de 5 cm de longitud cada una para despejar el ventana. Estas tienen un ángulo de apertura de 90°, tal como se muestra a continuación:

    El esquema que representa los datos de las dimensiones del ventana es:


    1. {r opcion3, echo=FALSE, results='asis'} include_tikz(tikz_opcion3, name = "opcion3", markup = "markdown", format = typ, packages = c("tikz"), width = "8cm")
    2. {r opcion4, echo=FALSE, results='asis'} include_tikz(tikz_opcion4, name = "opcion4", markup = "markdown", format = typ, packages = c("tikz"), width = "8cm")
    3. {r opcion1, echo=FALSE, results='asis'} include_tikz(tikz_opcion1, name = "opcion1", markup = "markdown", format = typ, packages = c("tikz"), width = "8cm")
    4. {r opcion2, echo=FALSE, results='asis'} include_tikz(tikz_opcion2, name = "opcion2", markup = "markdown", format = typ, packages = c("tikz"), width = "8cm")

    Solution

    La respuesta correcta es la opción que muestra un ventana con dimensiones de 15 cm de largo y 12 cm de ancho, con dos plantillass de 5 cm cada una.

    Para resolver este problema, debemos identificar el esquema que representa correctamente las dimensiones dadas: - Largo del ventana: 15 cm - Ancho del ventana: 12 cm - Longitud de cada plantillas: 5 cm - Ángulo de apertura: 90°

    La opción correcta muestra exactamente estas dimensiones, con el ventana rectangular y las dos plantillass ubicadas en la parte inferior, cada una con la longitud especificada.

    Las otras opciones muestran dimensiones incorrectas: - Opción B: Largo = 14 cm, Ancho = 10 cm - Opción C: Largo = 16 cm, Ancho = 11 cm - Opción D: Largo = 17 cm, Ancho = 14 cm
