Exam 1

  1. Question

    El centro comercial UltraCine registró la asistencia de espectadores durante una semana en sus diferentes salas 4DX que proyectaban películas de fantasía. Los datos se muestran en la siguiente tabla:

    Contexto de Formulación-Ejecución: Para analizar la tendencia central de asistencia y tomar decisiones sobre la programación de películas, el gerente necesita calcular la mediana de asistencia.

    ¿Cuál de las siguientes afirmaciones explica correctamente cómo calcular la mediana de asistencia para las 11 salas de cine?

    Nota: La mediana es la medida de tendencia central que divide el conjunto de datos ordenados en dos mitades iguales.


    1. La mediana es 403 porque se encuentra en la mitad exacta de los datos
    2. La mediana es 484 porque es el valor que más se repite en el conjunto de datos
    3. La mediana es 412.8 porque representa el promedio aritmético de todos los valores
    4. La mediana es 418 porque es el valor que divide el conjunto ordenado en dos mitades iguales

    Solution

    Para resolver este problema de Formulación-Ejecución, debemos aplicar el concepto de mediana y seguir un proceso sistemático de cálculo.

    Paso 1: Comprender el concepto de mediana

    La mediana es el valor que ocupa la posición central cuando los datos están ordenados de menor a mayor. Es una medida de tendencia central que divide el conjunto de datos en dos mitades iguales.

    Paso 2: Organizar los datos

    Datos de asistencia (presentados en la tabla): 588, 537, 418, 361, 403, 546, 226, 484, 456, 217, 305

    Datos ordenados de menor a mayor: 217, 226, 305, 361, 403, 418, 456, 484, 537, 546, 588

    Total de salas: n = 11

    Paso 3: Aplicar la fórmula de mediana según el número de datos

    Como tenemos un número impar de datos (n = 11 ), la mediana es el valor central.

    • Posición del valor central: (n + 1)/2 = ( 11 + 1)/2 = 6

    Mediana: posición 6 = 418

    Paso 4: Verificación del resultado

    La mediana calculada es 418, lo que significa que:

    • El 50% de las salas tuvieron una asistencia menor o igual a 418
    • El 50% de las salas tuvieron una asistencia mayor o igual a 418

    Paso 5: Análisis de las opciones

    Respuesta correcta: La mediana es 418 porque es el valor que divide el conjunto ordenado en dos mitades iguales

    ¿Por qué las otras opciones son incorrectas?

    • Opción B : La mediana es 412.8 porque representa el promedio aritmético de todos los valores Error conceptual: Confunde mediana con media aritmética.

    • Opción C : La mediana es 403 porque se encuentra en la mitad exacta de los datos Error en el procedimiento de cálculo.

    • Opción D : La mediana es 484 porque es el valor que más se repite en el conjunto de datos Error conceptual: Confunde mediana con moda.

    Conclusión

    La competencia de Formulación-Ejecución requiere que identifiquemos la estrategia correcta (ordenar datos y aplicar la fórmula de mediana) y la ejecutemos paso a paso para obtener el resultado correcto: 418.
