  1. Question

    El centro comercial Cine Boutique registró la asistencia de espectadores durante una semana en sus diferentes salas boutique que proyectaban películas de thriller. Los datos se muestran en la siguiente tabla:

    Contexto de Formulación-Ejecución: Para analizar la tendencia central de asistencia y tomar decisiones sobre la programación de películas, el gerente necesita calcular la mediana de asistencia.

    ¿Cuál de las siguientes afirmaciones explica correctamente cómo calcular la mediana de asistencia para las 15 salas de cine?

    Nota: La mediana es la medida de tendencia central que divide el conjunto de datos ordenados en dos mitades iguales.


    1. La mediana es 429 porque se encuentra en la mitad exacta de los datos
    2. La mediana es 435 porque es el valor que mejor representa el conjunto
    3. La mediana es 230 porque representa la diferencia entre el valor máximo y mínimo
    4. La mediana es 435 porque es el valor que divide el conjunto ordenado en dos mitades iguales

    Solution

    Para resolver este problema de Formulación-Ejecución, debemos aplicar el concepto de mediana y seguir un proceso sistemático de cálculo.

    Paso 1: Comprender el concepto de mediana

    La mediana es el valor que ocupa la posición central cuando los datos están ordenados de menor a mayor. Es una medida de tendencia central que divide el conjunto de datos en dos mitades iguales.

    Paso 2: Organizar los datos

    Datos de asistencia (presentados en la tabla): 427, 570, 600, 576, 513, 435, 420, 559, 370, 538, 387, 498, 429, 408, 379

    Datos ordenados de menor a mayor: 370, 379, 387, 408, 420, 427, 429, 435, 498, 513, 538, 559, 570, 576, 600

    Total de salas: n = 15

    Paso 3: Aplicar la fórmula de mediana según el número de datos

    Como tenemos un número impar de datos (n = 15 ), la mediana es el valor central.

    • Posición del valor central: (n + 1)/2 = ( 15 + 1)/2 = 8

    Mediana: posición 8 = 435

    Paso 4: Verificación del resultado

    La mediana calculada es 435, lo que significa que:

    • El 50% de las salas tuvieron una asistencia menor o igual a 435
    • El 50% de las salas tuvieron una asistencia mayor o igual a 435

    Paso 5: Análisis de las opciones

    Respuesta correcta: La mediana es 435 porque es el valor que divide el conjunto ordenado en dos mitades iguales

    ¿Por qué las otras opciones son incorrectas?

    • Opción B : La mediana es 230 porque representa la diferencia entre el valor máximo y mínimo Error conceptual: Confunde mediana con rango.

    • Opción C : La mediana es 429 porque se encuentra en la mitad exacta de los datos Error en el procedimiento de cálculo.

    • Opción D : La mediana es 435 porque es el valor que mejor representa el conjunto Error conceptual: Justificación incorrecta para el valor correcto.

    Conclusión

    La competencia de Formulación-Ejecución requiere que identifiquemos la estrategia correcta (ordenar datos y aplicar la fórmula de mediana) y la ejecutemos paso a paso para obtener el resultado correcto: 435.
