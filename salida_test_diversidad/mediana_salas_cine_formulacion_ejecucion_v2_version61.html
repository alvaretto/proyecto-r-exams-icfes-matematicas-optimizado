  1. Question

    El centro comercial Cine Indie registró la asistencia de espectadores durante una semana en sus diferentes salas independientes que proyectaban películas de documental. Los datos se muestran en la siguiente tabla:

    Contexto de Formulación-Ejecución: Para analizar la tendencia central de asistencia y tomar decisiones sobre la programación de películas, el gerente necesita calcular la mediana de asistencia.

    ¿Cuál de las siguientes afirmaciones explica correctamente cómo calcular la mediana de asistencia para las 13 salas de cine?

    Nota: La mediana es la medida de tendencia central que divide el conjunto de datos ordenados en dos mitades iguales.


    1. La mediana es 432 porque se obtiene al aplicar la fórmula (máximo + mínimo) / 2
    2. La mediana es 432 porque es el valor que divide el conjunto ordenado en dos mitades iguales
    3. La mediana es 578 porque representa el valor más frecuente
    4. La mediana es 359 porque está en la posición n/2 del conjunto ordenado

    Solution

    Para resolver este problema de Formulación-Ejecución, debemos aplicar el concepto de mediana y seguir un proceso sistemático de cálculo.

    Paso 1: Comprender el concepto de mediana

    La mediana es el valor que ocupa la posición central cuando los datos están ordenados de menor a mayor. Es una medida de tendencia central que divide el conjunto de datos en dos mitades iguales.

    Paso 2: Organizar los datos

    Datos de asistencia (presentados en la tabla): 273, 442, 487, 578, 215, 312, 500, 432, 304, 293, 540, 515, 359

    Datos ordenados de menor a mayor: 215, 273, 293, 304, 312, 359, 432, 442, 487, 500, 515, 540, 578

    Total de salas: n = 13

    Paso 3: Aplicar la fórmula de mediana según el número de datos

    Como tenemos un número impar de datos (n = 13 ), la mediana es el valor central.

    • Posición del valor central: (n + 1)/2 = ( 13 + 1)/2 = 7

    Mediana: posición 7 = 432

    Paso 4: Verificación del resultado

    La mediana calculada es 432, lo que significa que:

    • El 50% de las salas tuvieron una asistencia menor o igual a 432
    • El 50% de las salas tuvieron una asistencia mayor o igual a 432

    Paso 5: Análisis de las opciones

    Respuesta correcta: La mediana es 432 porque es el valor que divide el conjunto ordenado en dos mitades iguales

    ¿Por qué las otras opciones son incorrectas?

    • Opción A : La mediana es 359 porque está en la posición n/2 del conjunto ordenado Error en el procedimiento de cálculo.

    • Opción B : La mediana es 432 porque se obtiene al aplicar la fórmula (máximo + mínimo) / 2 Error en el procedimiento de cálculo.

    • Opción C : La mediana es 578 porque representa el valor más frecuente Error conceptual: Confunde mediana con moda.

    Conclusión

    La competencia de Formulación-Ejecución requiere que identifiquemos la estrategia correcta (ordenar datos y aplicar la fórmula de mediana) y la ejecutemos paso a paso para obtener el resultado correcto: 432.
