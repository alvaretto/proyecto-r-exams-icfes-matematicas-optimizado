Exam 1

  1. Question

    El centro comercial Cine Indie registró la asistencia de espectadores durante una semana en sus diferentes salas independientes que proyectaban películas de documental. Los datos se muestran en la siguiente tabla:

    Contexto de Formulación-Ejecución: Para analizar la tendencia central de asistencia y tomar decisiones sobre la programación de películas, el gerente necesita calcular la mediana de asistencia.

    ¿Cuál de las siguientes afirmaciones explica correctamente cómo calcular la mediana de asistencia para las 9 salas de cine?

    Nota: La mediana es la medida de tendencia central que divide el conjunto de datos ordenados en dos mitades iguales.


    1. La mediana es 578 porque se toma directamente el valor del medio de la tabla
    2. La mediana es 578 porque es el límite superior de los datos
    3. La mediana es 201 porque representa el valor más frecuente
    4. La mediana es 422 porque es el valor central (posición 5) en el conjunto de datos ordenados

    Solution

    Para resolver este problema de Formulación-Ejecución, debemos aplicar el concepto de mediana y seguir un proceso sistemático de cálculo.

    Paso 1: Comprender el concepto de mediana

    La mediana es el valor que ocupa la posición central cuando los datos están ordenados de menor a mayor. Es una medida de tendencia central que divide el conjunto de datos en dos mitades iguales.

    Paso 2: Organizar los datos

    Datos de asistencia (presentados en la tabla): 572, 399, 328, 422, 235, 429, 566, 201, 578

    Datos ordenados de menor a mayor: 201, 235, 328, 399, 422, 429, 566, 572, 578

    Total de salas: n = 9

    Paso 3: Aplicar la fórmula de mediana según el número de datos

    Como tenemos un número impar de datos (n = 9 ), la mediana es el valor central.

    • Posición del valor central: (n + 1)/2 = ( 9 + 1)/2 = 5

    Mediana: posición 5 = 422

    Paso 4: Verificación del resultado

    La mediana calculada es 422, lo que significa que:

    • El 50% de las salas tuvieron una asistencia menor o igual a 422
    • El 50% de las salas tuvieron una asistencia mayor o igual a 422

    Paso 5: Análisis de las opciones

    Respuesta correcta: La mediana es 422 porque es el valor central (posición 5) en el conjunto de datos ordenados

    ¿Por qué las otras opciones son incorrectas?

    • Opción A : La mediana es 578 porque es el límite superior de los datos Error conceptual: Confunde mediana con valor máximo.

    • Opción B : La mediana es 578 porque se toma directamente el valor del medio de la tabla Error procedimental: No comprende que los datos deben ordenarse.

    • Opción C : La mediana es 201 porque representa el valor más frecuente Error conceptual: Confunde mediana con moda.

    Conclusión

    La competencia de Formulación-Ejecución requiere que identifiquemos la estrategia correcta (ordenar datos y aplicar la fórmula de mediana) y la ejecutemos paso a paso para obtener el resultado correcto: 422.
