# 🎯 ICFES Mathematics R-Exams Repository

## 📋 PROJECT OVERVIEW

**Sistema integral para generar exámenes de matemáticas automatizados alineados con estándares ICFES (Instituto Colombiano para la Evaluación de la Educación) usando el framework R-exams.**

### Key Technologies
- **Primary Language**: R (4.x)
- **Framework**: R-exams (2.4+)
- **Document Processing**: R Markdown, LaTeX, TikZ
- **Visualization**: Python (via reticulate), ggplot2, matplotlib
- **Output Formats**: PDF, HTML, Moodle XML, NOPS (scannable)
- **Project Type**: RStudio Project (.Rproj)

### Core Purpose
- Generate randomized mathematics exercises for Colombian educational standards
- Support multiple output formats for different assessment platforms
- Maintain ICFES metadata alignment for educational compliance
- Provide 300+ unique variations per exercise through advanced randomization

### Mathematical Content Areas
- **Álgebra y Cálculo**: Functions, equations, optimization, basic calculus
- **Geometría**: Areas, volumes, Pythagorean theorem, trigonometry, transformations
- **Estadística y Probabilidad**: Central tendency, statistical graphics, basic probability, frequency distributions

test_that("Version diversity test", {
  versiones <- list()
  for(i in 1:1000) {
    datos_test <- generar_datos()
    versiones[[i]] <- digest::digest(datos_test)

## ⚠️ CRITICAL RESTRICTIONS

1. **NEVER** use fixed set.seed() - must be random
2. **ALWAYS** include version diversity test
3. **MANDATORY** complete ICFES metadata
4. **REQUIRED** minimum 4 answer options
5. **ESSENTIAL** detailed explanation in Solution

### ⚠️ **CRITICAL RESTRICTION - SPECIAL CHARACTERS:**
- **DO NOT USE UNICODE SPECIAL CHARACTERS** anywhere in R-exams code
- **USE ONLY**:
  - LaTeX expressions for mathematical symbols: `$\alpha$`, `$\beta$`, `$\pi$`, `$\sum$`, `$\int$`, etc.
  - TikZ syntax for diagrams and geometric figures
  - Standard ASCII characters for text
- **COMPLETELY AVOID**:
  - Unicode symbols: α, β, π, ∑, ∫, ≤, ≥, ≠, etc.
  - Direct special characters in text
  - Emojis or decorative symbols
- **CORRECT EXAMPLE**: `The function $f(x) = \pi x^2$ has derivative $f'(x) = 2\pi x$`
- **INCORRECT EXAMPLE**: `The function f(x) = π x² has derivative f'(x) = 2π x`

### Image Analysis for Mathematical Exercise Generation

When analyzing mathematical images for R-exams generation:

#### Analysis Process
1. **Structural Analysis**: Identify mathematical elements (equations, graphics, tables) and relationships
2. **Detailed Extraction**: Recognize variables, axes, data, relationships, and visual components
3. **Interpretation**: Determine central and secondary mathematical concepts

#### Technical Specifications
1. **Specific Technologies**:
   - Mathematical expressions: LaTeX code with R-exams syntax
   - Tables: TikZ code with R-exams syntax (include_tikz())
   - Graphics and visualizations: Python code (Reticulate) with R-exams syntax
   - Rest of document: R code with R-exams syntax

2. **Document Structure**:
   - Initial configuration (ICFES metadata, libraries)
   - Variable definition and randomization
   - Visual element generation
   - Question formulation and options
   - Detailed solution
   - Meta-information for R-exams

3. **Configuration**:
   - Optimization for multiple formats: exams2moodle, exams2pdf, exams2pandoc, exams2nops
   - Font and special character handling
   - Cross-platform compatibility
   - Random seed control

### Advanced Randomization Requirements

1. **Requirements**:
   - Randomize at least 10 different parameters
   - Guarantee minimum 300 problem variants
   - Preserve semantic and mathematical coherence
   - Randomize visual elements while maintaining clarity

2. **Techniques**:
   - Use pseudorandom seed generators
   - Implement contextual element lists
   - Create parametric variations with validity constraints
   - Generate correlated data with realistic patterns

3. **Validation**:
   - Implement unit tests to verify coherence
   - Verify adequate ranges for generated values
   - Check mathematical validity in all variants
