## Project Overview

Sistema integral para generar exámenes de matemáticas automatizados alineados con estándares ICFES (Instituto Colombiano para la Evaluación de la Educación) usando el framework R-exams.

### Key Technologies
- **Primary Language**: R (4.x)
- **Framework**: R-exams (2.4+)
- **Document Processing**: R Markdown, LaTeX, TikZ
- **Visualization**: Python (via reticulate), ggplot2, matplotlib
- **Output Formats**: PDF, HTML, Moodle XML, NOPS (scannable)
- **Project Type**: RStudio Project (.Rproj)

### Core Purpose
- Generate randomized mathematics exercises for Colombian educational standards
- Support multiple output formats for different assessment platforms
- Maintain ICFES metadata alignment for educational compliance
- Provide 300+ unique variations per exercise through advanced randomization

### ICFES Metadata System

All exercises must include ICFES metadata for educational alignment:

```yaml
icfes:
  competencia: 
    - interpretacion_representacion  # or formulacion_ejecucion, argumentacion
  nivel_dificultad: 2                # 1-4 scale
  contenido:
    categoria: estadistica           # algebra_calculo, geometria, estadistica
    tipo: generico                   # generico, no_generico
  contexto: familiar                 # familiar, laboral, comunitario, matematico
  eje_axial: eje4                    # eje1, eje2, eje3, eje4
  componente: aleatorio              # geometrico_metrico, numerico_variacional, aleatorio
```

### Randomization Requirements

#### Minimum Standards
- Randomize at least 10 different parameters
- Generate minimum 300 unique problem variants
- Maintain mathematical and semantic coherence
- Validate all generated values for mathematical validity

#### Randomization Techniques
- Use `set.seed(sample(1:10000, 1))` for reproducible randomization
- Create context lists for varied problem scenarios
- Implement parameter ranges with validation
- Generate correlated data with realistic patterns

### Code Quality Standards

#### Naming Conventions
- Files: `topic_description_level_version.Rmd` (e.g., `grafico_circular_bienes_v0.Rmd`)
- Variables: Use descriptive Spanish names for context variables
- Functions: Follow R conventions with snake_case

#### Required Testing
- Each Lab directory should include `ejecutar_pruebas.R` or similar
- Use `pruebas_unitarias.R` for unit testing
- Implement visual validation for graphics
- Test multiple output formats (HTML, PDF, Moodle)

#### Output Management
- Generate outputs in `salida/` subdirectories
- Support multiple formats: `.xml` (Moodle), `.docx`, `.pdf`, `.nops`
- Include both solution and no-solution versions

### Technology Integration

#### Python Integration (via reticulate)
- Use for advanced visualizations (matplotlib)
- Configure with `use_python(Sys.which("python"), required = TRUE)`
- Install required packages: numpy, matplotlib, pandas, scipy

#### LaTeX/TikZ Integration
- Use for mathematical diagrams and complex layouts
- Configure TikZ packages in setup chunk
- Support for mathematical notation and symbols
- **🌐 ENRIQUECIMIENTO RECURSIVO**: Buscar documentación TikZ web para complementar proyecto local

#### Multi-format Output
- **PDF**: Professional print-ready exams
- **HTML**: Web-based testing and preview
- **Moodle XML**: LMS integration
- **NOPS**: Scannable bubble sheets
