🧮✨ **Proyecto 22-S2-2025-SEDQ: Generación Automática de Ejercicios de Fracciones**

🎯 **¿Qué es?** 

Sistema inteligente que genera miles de versiones únicas de problemas de reparto proporcional con fracciones, alineado con estándares ICFES.

🔧 **Innovaciones técnicas:**

• Sistema de concordancia de género automática (evita errores como "una maratón")
• Validación matemática con tests unitarios
• Generación de distractores inteligentes anti-duplicados
• Integración R + Python para visualizaciones profesionales

📊 **Características:**

• 300+ versiones únicas por ejecución
• Coherencia semántica perfecta en español
• Gráficos adaptativos con paletas de colores
• Metadatos educativos estructurados

🎓 **Impacto educativo:**

• Problemas contextualizados (competencias deportivas)
• Soluciones paso a paso pedagógicas
• Variabilidad controlada para evaluaciones
• Compatible con plataformas LMS

💻 **Stack tecnológico:** #RStats #Python #LaTeX #rexams #matplotlib

🔗 **Resultado:** Herramienta robusta para crear contenido educativo de matemáticas de alta calidad, manteniendo rigor académico y riqueza lingüística.
