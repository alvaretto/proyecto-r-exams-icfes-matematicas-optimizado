Exam 1

  1. Question

    Mariana desea saber cuánto sustancia se necesita para llenar el cilindro interno, pero solamente cuenta con las medidas de las dimensiones que muestra la figura.

    ¿Cuál medida le falta a Mariana para hallar la cantidad deseada?


    1. Altura del cilindro.
    2. Diámetro externo.
    3. Perímetro del cilindro.
    4. Radio externo.

    Solution

    La respuesta correcta es: Altura del cilindro.

    Para calcular el volumen de sustancia necesario para llenar el cilindro central, necesitamos calcular el volumen de un cilindro, cuya fórmula es:

    V=π⋅r2⋅hV = \pi \cdot r^2 \cdot h

    Donde: - rr es el radio (en este caso, el radio interno = 3.1 dm) - hh es la altura del cilindro

    En el problema se nos proporciona: - Diámetro externo = 9.4 dm - Radio interno = 3.1 dm

    Sin embargo, no se nos proporciona la altura del cilindro, que es esencial para calcular el volumen. Por lo tanto, a Mariana le falta conocer la altura del cilindro para poder calcular la cantidad de sustancia necesaria.

    Si tuviéramos la altura, el volumen se calcularía así: V=π⋅(3.1)2⋅h=30.19⋅hV = \pi \cdot (3.1)^2 \cdot h = 30.19 \cdot h dm³
