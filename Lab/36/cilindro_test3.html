Exam 3

  1. Question

    Camilo desea saber cuánto solución se necesita para llenar el cilindro interno, pero solamente cuenta con las medidas de las dimensiones que muestra la figura.

    ¿Cuál medida le falta a Camilo para hallar la cantidad deseada?


    1. Perímetro del cilindro.
    2. Radio externo.
    3. Diámetro externo.
    4. Altura del cilindro.

    Solution

    La respuesta correcta es: Altura del cilindro.

    Para calcular el volumen de solución necesario para llenar el cilindro medio, necesitamos calcular el volumen de un cilindro, cuya fórmula es:

    V=π⋅r2⋅hV = \pi \cdot r^2 \cdot h

    Donde: - rr es el radio (en este caso, el radio interno = 0.3 m) - hh es la altura del cilindro

    En el problema se nos proporciona: - Diámetro externo = 0.9 m - Radio interno = 0.3 m

    Sin embargo, no se nos proporciona la altura del cilindro, que es esencial para calcular el volumen. Por lo tanto, a Camilo le falta conocer la altura del cilindro para poder calcular la cantidad de solución necesaria.

    Si tuviéramos la altura, el volumen se calcularía así: V=π⋅(0.3)2⋅h=0.28⋅hV = \pi \cdot (0.3)^2 \cdot h = 0.28 \cdot h m³
