Exam 4

  1. Question

    Isabella desea saber cuánto fluido se necesita para llenar el conducto interno, pero solamente cuenta con las medidas de las dimensiones que muestra la figura.

    ¿Cuál medida le falta a Isabella para hallar la cantidad deseada?


    1. Radio externo.
    2. Diámetro externo.
    3. Perímetro del cilindro.
    4. Altura del cilindro.

    Solution

    La respuesta correcta es: Altura del cilindro.

    Para calcular el volumen de fluido necesario para llenar el conducto interno, necesitamos calcular el volumen de un cilindro, cuya fórmula es:

    V=π⋅r2⋅hV = \pi \cdot r^2 \cdot h

    Donde: - rr es el radio (en este caso, el radio interno = 0.2 m) - hh es la altura del cilindro

    En el problema se nos proporciona: - Diámetro externo = 0.9 m - Radio interno = 0.2 m

    Sin embargo, no se nos proporciona la altura del cilindro, que es esencial para calcular el volumen. Por lo tanto, a Isabella le falta conocer la altura del cilindro para poder calcular la cantidad de fluido necesaria.

    Si tuviéramos la altura, el volumen se calcularía así: V=π⋅(0.2)2⋅h=0.13⋅hV = \pi \cdot (0.2)^2 \cdot h = 0.13 \cdot h m³
