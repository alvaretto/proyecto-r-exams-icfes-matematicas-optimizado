Exam 1

  1. Question

    Daniel necesita determinar el volumen de combustible que puede contener el cilindro interno pero solamente cuenta con las medidas de las dimensiones que muestra la figura.

    ¿Qué medida le falta a Daniel para hallar la cantidad deseada?


    1. Radio externo
    2. Diámetro externo
    3. Altura del cilindro
    4. Perímetro del cilindro

    Solution

    Para resolver este problema, debemos analizar qué información necesitamos para calcular el volumen del cilindro interno, que determinará la cantidad de combustible que puede contener.

    El volumen de un cilindro se calcula con la fórmula: V=π⋅r2⋅hV = \pi \cdot r^2 \cdot h

    Donde: - rr es el radio del cilindro - hh es la altura del cilindro

    En la figura se muestra: - Radio interno = 1.8 m - Grosor = 0.6 m (que determina el radio externo = 2.4 m)

    Podemos calcular: - Radio externo = Radio interno + Grosor = 1.8 + 0.6 = 2.4 m - Diámetro externo = 2 × Radio externo = 2 × 2.4 = 4.8 m

    Para calcular el volumen del cilindro interno necesitamos: 1. El radio interno (ya lo tenemos: 1.8 m) 2. La altura del cilindro (esta información falta)

    Por lo tanto, a Daniel le falta conocer la altura del cilindro para poder calcular la cantidad de combustible que puede contener el cilindro interno.


    1. Este es incorrecto. Conocer el radio externo no es suficiente para calcular el volumen, ya tenemos esta información o no es necesaria
    2. Este es incorrecto. Conocer el diámetro externo no es suficiente para calcular el volumen, ya tenemos esta información o no es necesaria
    3. Este es correcto. Para calcular el volumen del cilindro interno necesitamos conocer su altura del cilindro
    4. Este es incorrecto. Conocer la perímetro del cilindro no es suficiente para calcular el volumen, ya tenemos esta información o no es necesaria
