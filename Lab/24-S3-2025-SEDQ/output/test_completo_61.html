Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salas de cine de un centro comercial es 338 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 339
    2. 338
    3. 337
    4. 323

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 338 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salas de cine: A, C, F, B, D, E, G
    • Sus valores son: 266, 485, 338, 262, 387, 392, N
    • La mediana del conjunto es 338
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 338 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 338 .

    Análisis de casos

    Los valores conocidos son: 266, 262, 485, 387, 392, 338

    Analicemos dónde puede ubicarse N para que la mediana sea 338:


    Caso 1: Si N es menor o igual a 262 (muy pequeño) - El valor 338 no quedaría en posición 4 - Mediana diferente de 338

    Caso 2: Si 262 < N < 338 - El valor 338 queda en posición 4 - Mediana = 338 (CORRECTO)

    Caso 3: Si N = 338 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 338 - El valor 338 no estaría en posición 4 - Mediana diferente de 338

    Conclusión

    Para que la mediana sea 338 , N debe cumplir: 262 < N < 338

    El mayor valor posible para N es ** 337 ** (justo menor que 338 ).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
