Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 371 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 362
    2. 334
    3. 408
    4. 370

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 371 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: B, E, A, D, C
    • Sus valores son: 511, N, 300, 371, 486
    • La mediana del conjunto es 371
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 371 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 371 .

    Análisis de casos

    Los valores conocidos son: 300, 511, 486, 371

    Analicemos dónde puede ubicarse N para que la mediana sea 371:


    Caso 1: Si N es menor o igual a 300 (muy pequeño) - El valor 371 no quedaría en posición 3 - Mediana diferente de 371

    Caso 2: Si 300 < N < 371 - El valor 371 queda en posición 3 - Mediana = 371 (CORRECTO)

    Caso 3: Si N = 371 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 371 - El valor 371 no estaría en posición 3 - Mediana diferente de 371

    Conclusión

    Para que la mediana sea 371 , N debe cumplir: 300 < N < 371

    El mayor valor posible para N es ** 370 ** (justo menor que 371 ).
