Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 auditorios de un centro cultural es 495 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 494
    2. 495
    3. 501
    4. 481

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 495 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 auditorios: C, A, E, D, F, B, G
    • Sus valores son: 581, 431, 575, 535, 495, 429, N
    • La mediana del conjunto es 495
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 495 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 495 .

    Análisis de casos

    Los valores conocidos son: 431, 429, 581, 535, 575, 495

    Analicemos dónde puede ubicarse N para que la mediana sea 495:


    Caso 1: Si N es menor o igual a 429 (muy pequeño) - El valor 495 no quedaría en posición 4 - Mediana diferente de 495

    Caso 2: Si 429 < N < 495 - El valor 495 queda en posición 4 - Mediana = 495 (CORRECTO)

    Caso 3: Si N = 495 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 495 - El valor 495 no estaría en posición 4 - Mediana diferente de 495

    Conclusión

    Para que la mediana sea 495 , N debe cumplir: 429 < N < 495

    El mayor valor posible para N es ** 494 ** (justo menor que 495 ).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
