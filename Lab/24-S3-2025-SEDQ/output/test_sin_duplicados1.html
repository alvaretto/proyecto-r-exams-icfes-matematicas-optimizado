Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 376 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 345
    2. 375
    3. 386
    4. 394

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 376 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: A, E, C, D, B
    • Sus valores son: 238, N, 443, 376, 430
    • La mediana del conjunto es 376
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 376 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 376 .

    Análisis de casos

    Los valores conocidos son: 238, 430, 443, 376

    Analicemos dónde puede ubicarse N para que la mediana sea 376:


    Caso 1: Si N es menor o igual a 238 (muy pequeño) - El valor 376 no quedaría en posición 3 - Mediana diferente de 376

    Caso 2: Si 238 < N < 376 - El valor 376 queda en posición 3 - Mediana = 376 (CORRECTO)

    Caso 3: Si N = 376 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 376 - El valor 376 no estaría en posición 3 - Mediana diferente de 376

    Conclusión

    Para que la mediana sea 376 , N debe cumplir: 238 < N < 376

    El mayor valor posible para N es ** 375 ** (justo menor que 376 ).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
