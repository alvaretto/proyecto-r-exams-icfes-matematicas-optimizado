Exam 2

  1. Question

    Si la mediana de la asistencia a las 9 canchas de tenis de un complejo deportivo es 412 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 412
    2. 412
    3. 411
    4. 397

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 412 en un conjunto de 9 valores.

    Datos conocidos:

    • Tenemos 9 canchas de tenis: H, G, E, A, F, D, C, B, I
    • Sus valores son: 412, 555, 559, 373, 537, 462, 316, 296, N
    • La mediana del conjunto es 412
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 9 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5).

    Para que la mediana sea 412, cuando ordenemos los 9 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 412.

    Análisis de casos

    Los valores conocidos son: 373, 296, 316, 462, 559, 537, 555, 412

    Analicemos dónde puede ubicarse N para que la mediana sea 412:


    Caso 1: Si N es menor o igual a 296 (muy pequeño) - Orden: N, 296, 316, 373, 412, 462, 537, 555, 559 - Mediana = 316 diferente de 412

    Caso 2: Si 296 < N < 412 - El valor 412 queda en posición 5 - Mediana = 412 (CORRECTO)

    Caso 3: Si N = 412 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 412 - El valor 412 no estaría en posición 5 - Mediana diferente de 412

    Conclusión

    Para que la mediana sea 412 , N debe cumplir: 296 < N < 412

    El mayor valor posible para N es 411 (justo menor que 412).
