Exam 3

  1. Question

    Si la mediana de la asistencia a las 5 canchas de tenis de un complejo deportivo es 480 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 446
    2. 480
    3. 432
    4. 479

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 480 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 canchas de tenis: B, A, D, E, C
    • Sus valores son: 576, 377, 480, N, 556
    • La mediana del conjunto es 480
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 480 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 480 .

    Análisis de casos

    Los valores conocidos son: 377, 576, 556, 480

    Analicemos dónde puede ubicarse N para que la mediana sea 480:


    Caso 1: Si N es menor o igual a 377 (muy pequeño) - El valor 480 no quedaría en posición 3 - Mediana diferente de 480

    Caso 2: Si 377 < N < 480 - El valor 480 queda en posición 3 - Mediana = 480 (CORRECTO)

    Caso 3: Si N = 480 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 480 - El valor 480 no estaría en posición 3 - Mediana diferente de 480

    Conclusión

    Para que la mediana sea 480 , N debe cumplir: 377 < N < 480

    El mayor valor posible para N es ** 479 ** (justo menor que 480 ).
