Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 464 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 418
    2. 463
    3. 449
    4. 464

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 464 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: A, E, C, D, B
    • Sus valores son: 399, N, 547, 464, 522
    • La mediana del conjunto es 464
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 464 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 464 .

    Análisis de casos

    Los valores conocidos son: 399, 522, 547, 464

    Analicemos dónde puede ubicarse N para que la mediana sea 464:


    Caso 1: Si N es menor o igual a 399 (muy pequeño) - El valor 464 no quedaría en posición 3 - Mediana diferente de 464

    Caso 2: Si 399 < N < 464 - El valor 464 queda en posición 3 - Mediana = 464 (CORRECTO)

    Caso 3: Si N = 464 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 464 - El valor 464 no estaría en posición 3 - Mediana diferente de 464

    Conclusión

    Para que la mediana sea 464 , N debe cumplir: 399 < N < 464

    El mayor valor posible para N es ** 463 ** (justo menor que 464 ).

    2. Verdadero
    3. Falso
    4. Falso
