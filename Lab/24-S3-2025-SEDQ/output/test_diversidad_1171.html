Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 atracciones de un parque temático es 460 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 460
    2. 446
    3. 485
    4. 459

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 460 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 atracciones: F, G, C, B, A, D, E
    • Sus valores son: 460, N, 498, 332, 366, 551, 509
    • La mediana del conjunto es 460
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 460 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 460 .

    Análisis de casos

    Los valores conocidos son: 366, 332, 498, 551, 509, 460

    Analicemos dónde puede ubicarse N para que la mediana sea 460:


    Caso 1: Si N es menor o igual a 332 (muy pequeño) - El valor 460 no quedaría en posición 4 - Mediana diferente de 460

    Caso 2: Si 332 < N < 460 - El valor 460 queda en posición 4 - Mediana = 460 (CORRECTO)

    Caso 3: Si N = 460 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 460 - El valor 460 no estaría en posición 4 - Mediana diferente de 460

    Conclusión

    Para que la mediana sea 460 , N debe cumplir: 332 < N < 460

    El mayor valor posible para N es ** 459 ** (justo menor que 460 ).
