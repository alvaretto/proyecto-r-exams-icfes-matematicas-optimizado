Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 auditorios de un centro cultural es 430 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 445
    2. 395
    3. 429
    4. 459

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 430 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 auditorios: A, D, E, C, B
    • Sus valores son: 304, 430, N, 468, 511
    • La mediana del conjunto es 430
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 430 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 430 .

    Análisis de casos

    Los valores conocidos son: 304, 511, 468, 430

    Analicemos dónde puede ubicarse N para que la mediana sea 430:


    Caso 1: Si N es menor o igual a 304 (muy pequeño) - El valor 430 no quedaría en posición 3 - Mediana diferente de 430

    Caso 2: Si 304 < N < 430 - El valor 430 queda en posición 3 - Mediana = 430 (CORRECTO)

    Caso 3: Si N = 430 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 430 - El valor 430 no estaría en posición 3 - Mediana diferente de 430

    Conclusión

    Para que la mediana sea 430 , N debe cumplir: 304 < N < 430

    El mayor valor posible para N es ** 429 ** (justo menor que 430 ).
