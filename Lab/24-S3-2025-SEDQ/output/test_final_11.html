Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 auditorios de un centro cultural es 469 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 469
    2. 458
    3. 468
    4. 474

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 469 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 auditorios: C, B, E, A, D, F, G
    • Sus valores son: 495, 400, 497, 401, 557, 469, N
    • La mediana del conjunto es 469
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 469 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 469 .

    Análisis de casos

    Los valores conocidos son: 401, 400, 495, 557, 497, 469

    Analicemos dónde puede ubicarse N para que la mediana sea 469:


    Caso 1: Si N es menor o igual a 400 (muy pequeño) - El valor 469 no quedaría en posición 4 - Mediana diferente de 469

    Caso 2: Si 400 < N < 469 - El valor 469 queda en posición 4 - Mediana = 469 (CORRECTO)

    Caso 3: Si N = 469 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 469 - El valor 469 no estaría en posición 4 - Mediana diferente de 469

    Conclusión

    Para que la mediana sea 469 , N debe cumplir: 400 < N < 469

    El mayor valor posible para N es 468 (justo menor que 469).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
