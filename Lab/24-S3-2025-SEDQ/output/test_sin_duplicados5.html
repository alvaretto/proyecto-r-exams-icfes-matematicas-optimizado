Exam 5

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 442 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 434
    2. 404
    3. 441
    4. 486

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 442 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: D, E, B, A, C
    • Sus valores son: 442, N, 538, 391, 592
    • La mediana del conjunto es 442
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 442 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 442 .

    Análisis de casos

    Los valores conocidos son: 391, 538, 592, 442

    Analicemos dónde puede ubicarse N para que la mediana sea 442:


    Caso 1: Si N es menor o igual a 391 (muy pequeño) - El valor 442 no quedaría en posición 3 - Mediana diferente de 442

    Caso 2: Si 391 < N < 442 - El valor 442 queda en posición 3 - Mediana = 442 (CORRECTO)

    Caso 3: Si N = 442 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 442 - El valor 442 no estaría en posición 3 - Mediana diferente de 442

    Conclusión

    Para que la mediana sea 442 , N debe cumplir: 391 < N < 442

    El mayor valor posible para N es ** 441 ** (justo menor que 442 ).
