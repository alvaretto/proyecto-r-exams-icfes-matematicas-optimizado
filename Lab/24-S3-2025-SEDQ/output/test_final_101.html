Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 auditorios de un centro cultural es 355 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 355
    2. 356
    3. 345
    4. 354

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 355 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 auditorios: C, A, B, D, E
    • Sus valores son: 489, 218, 473, 355, N
    • La mediana del conjunto es 355
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 355 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 355 .

    Análisis de casos

    Los valores conocidos son: 218, 473, 489, 355

    Analicemos dónde puede ubicarse N para que la mediana sea 355:


    Caso 1: Si N es menor o igual a 218 (muy pequeño) - El valor 355 no quedaría en posición 3 - Mediana diferente de 355

    Caso 2: Si 218 < N < 355 - El valor 355 queda en posición 3 - Mediana = 355 (CORRECTO)

    Caso 3: Si N = 355 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 355 - El valor 355 no estaría en posición 3 - Mediana diferente de 355

    Conclusión

    Para que la mediana sea 355 , N debe cumplir: 218 < N < 355

    El mayor valor posible para N es 354 (justo menor que 355).


    1. Falso
    2. Falso
    3. Falso
    4. Verdadero
