Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salas de cine de un centro comercial es 406 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 378
    2. 406
    3. 405
    4. 382

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 406 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salas de cine: A, E, F, C, D, B, G
    • Sus valores son: 345, 465, 406, 483, 493, 286, N
    • La mediana del conjunto es 406
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 406 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 406 .

    Análisis de casos

    Los valores conocidos son: 345, 286, 483, 493, 465, 406

    Analicemos dónde puede ubicarse N para que la mediana sea 406:


    Caso 1: Si N es menor o igual a 286 (muy pequeño) - El valor 406 no quedaría en posición 4 - Mediana diferente de 406

    Caso 2: Si 286 < N < 406 - El valor 406 queda en posición 4 - Mediana = 406 (CORRECTO)

    Caso 3: Si N = 406 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 406 - El valor 406 no estaría en posición 4 - Mediana diferente de 406

    Conclusión

    Para que la mediana sea 406 , N debe cumplir: 286 < N < 406

    El mayor valor posible para N es ** 405 ** (justo menor que 406 ).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
