Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 484 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 485
    2. 475
    3. 484
    4. 483

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 484 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: B, C, D, A, E
    • Sus valores son: 554, 510, 484, 375, N
    • La mediana del conjunto es 484
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 484 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 484 .

    Análisis de casos

    Los valores conocidos son: 375, 554, 510, 484

    Analicemos dónde puede ubicarse N para que la mediana sea 484:


    Caso 1: Si N es menor o igual a 375 (muy pequeño) - El valor 484 no quedaría en posición 3 - Mediana diferente de 484

    Caso 2: Si 375 < N < 484 - El valor 484 queda en posición 3 - Mediana = 484 (CORRECTO)

    Caso 3: Si N = 484 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 484 - El valor 484 no estaría en posición 3 - Mediana diferente de 484

    Conclusión

    Para que la mediana sea 484 , N debe cumplir: 375 < N < 484

    El mayor valor posible para N es ** 483 ** (justo menor que 484 ).
