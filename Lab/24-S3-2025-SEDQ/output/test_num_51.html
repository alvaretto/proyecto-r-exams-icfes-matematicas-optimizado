Exam 1

  1. Question

    Si la mediana de la asistencia a las 10 atracciones de un parque temático es 428 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 413
    2. 437
    3. 427
    4. 428

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 428 en un conjunto de 10 valores.

    Datos conocidos:

    • Tenemos 10 atracciones: H, A, I, F, E, B, C, G, D, J
    • Sus valores son: 528, 285, 428, 457, 481, 355, 313, 488, 543, N
    • La mediana del conjunto es 428
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 10 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5).

    Para que la mediana sea 428, cuando ordenemos los 10 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 428.

    Análisis de casos

    Los valores conocidos son: 285, 355, 313, 543, 481, 457, 488, 528, 428

    Analicemos dónde puede ubicarse N para que la mediana sea 428:


    Caso 1: Si N es menor o igual a 285 (muy pequeño) - Orden: N, 285, 313, 355, 428, 457, 481, 488, 528, 543 - Mediana = 313 diferente de 428

    Caso 2: Si 285 < N < 428 - El valor 428 queda en posición 5 - Mediana = 428 (CORRECTO)

    Caso 3: Si N = 428 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 428 - El valor 428 no estaría en posición 5 - Mediana diferente de 428

    Conclusión

    Para que la mediana sea 428 , N debe cumplir: 285 < N < 428

    El mayor valor posible para N es 427 (justo menor que 428).

    2. Falso
