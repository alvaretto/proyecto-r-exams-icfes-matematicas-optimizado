Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 salones de un centro de convenciones es 456 y no hay dos salones con el mismo número de participantes, ¿cuál es el mayor valor posible para “N”?


    1. 455
    2. 463
    3. 456
    4. 475

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 456 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 salones: C, A, E, D, B
    • Sus valores son: 596, 323, N, 456, 525
    • La mediana del conjunto es 456
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 456 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 456 .

    Análisis de casos

    Los valores conocidos son: 323, 525, 596, 456

    Analicemos dónde puede ubicarse N para que la mediana sea 456:


    Caso 1: Si N es menor o igual a 323 (muy pequeño) - El valor 456 no quedaría en posición 3 - Mediana diferente de 456

    Caso 2: Si 323 < N < 456 - El valor 456 queda en posición 3 - Mediana = 456 (CORRECTO)

    Caso 3: Si N = 456 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 456 - El valor 456 no estaría en posición 3 - Mediana diferente de 456

    Conclusión

    Para que la mediana sea 456 , N debe cumplir: 323 < N < 456

    El mayor valor posible para N es ** 455 ** (justo menor que 456 ).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
