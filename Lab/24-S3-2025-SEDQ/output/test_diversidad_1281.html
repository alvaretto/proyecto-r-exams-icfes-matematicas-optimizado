Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 canchas de tenis de un complejo deportivo es 428 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 428
    2. 443
    3. 427
    4. 396

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 428 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 canchas de tenis: A, D, C, B, G, F, E
    • Sus valores son: 295, 483, 534, 386, N, 428, 535
    • La mediana del conjunto es 428
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 428 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 428 .

    Análisis de casos

    Los valores conocidos son: 295, 386, 534, 483, 535, 428

    Analicemos dónde puede ubicarse N para que la mediana sea 428:


    Caso 1: Si N es menor o igual a 295 (muy pequeño) - El valor 428 no quedaría en posición 4 - Mediana diferente de 428

    Caso 2: Si 295 < N < 428 - El valor 428 queda en posición 4 - Mediana = 428 (CORRECTO)

    Caso 3: Si N = 428 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 428 - El valor 428 no estaría en posición 4 - Mediana diferente de 428

    Conclusión

    Para que la mediana sea 428 , N debe cumplir: 295 < N < 428

    El mayor valor posible para N es ** 427 ** (justo menor que 428 ).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
