Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salones de un centro de convenciones es 458 y no hay dos salones con el mismo número de participantes, ¿cuál es el mayor valor posible para “N”?


    1. 437
    2. 412
    3. 457
    4. 458

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 458 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salones: E, D, C, A, G, F, B
    • Sus valores son: 510, 564, 488, 427, N, 458, 385
    • La mediana del conjunto es 458
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 458 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 458 .

    Análisis de casos

    Los valores conocidos son: 427, 385, 488, 564, 510, 458

    Analicemos dónde puede ubicarse N para que la mediana sea 458:


    Caso 1: Si N es menor o igual a 385 (muy pequeño) - El valor 458 no quedaría en posición 4 - Mediana diferente de 458

    Caso 2: Si 385 < N < 458 - El valor 458 queda en posición 4 - Mediana = 458 (CORRECTO)

    Caso 3: Si N = 458 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 458 - El valor 458 no estaría en posición 4 - Mediana diferente de 458

    Conclusión

    Para que la mediana sea 458 , N debe cumplir: 385 < N < 458

    El mayor valor posible para N es ** 457 ** (justo menor que 458 ).
