Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salas de cine de un centro comercial es 387 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 348
    2. 390
    3. 426
    4. 386

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 387 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salas de cine: B, C, A, G, F, D, E
    • Sus valores son: 332, 491, 318, N, 387, 440, 532
    • La mediana del conjunto es 387
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 387 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 387 .

    Análisis de casos

    Los valores conocidos son: 318, 332, 491, 440, 532, 387

    Analicemos dónde puede ubicarse N para que la mediana sea 387:


    Caso 1: Si N es menor o igual a 318 (muy pequeño) - El valor 387 no quedaría en posición 4 - Mediana diferente de 387

    Caso 2: Si 318 < N < 387 - El valor 387 queda en posición 4 - Mediana = 387 (CORRECTO)

    Caso 3: Si N = 387 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 387 - El valor 387 no estaría en posición 4 - Mediana diferente de 387

    Conclusión

    Para que la mediana sea 387 , N debe cumplir: 318 < N < 387

    El mayor valor posible para N es ** 386 ** (justo menor que 387 ).

    2. Falso
    3. Falso
    4. Verdadero
