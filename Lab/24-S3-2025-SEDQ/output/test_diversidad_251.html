Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salas de cine de un centro comercial es 308 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 307
    2. 277
    3. 290
    4. 279

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 308 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salas de cine: D, B, C, A, G, F, E
    • Sus valores son: 395, 228, 424, 267, N, 308, 335
    • La mediana del conjunto es 308
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 308 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 308 .

    Análisis de casos

    Los valores conocidos son: 267, 228, 424, 395, 335, 308

    Analicemos dónde puede ubicarse N para que la mediana sea 308:


    Caso 1: Si N es menor o igual a 228 (muy pequeño) - El valor 308 no quedaría en posición 4 - Mediana diferente de 308

    Caso 2: Si 228 < N < 308 - El valor 308 queda en posición 4 - Mediana = 308 (CORRECTO)

    Caso 3: Si N = 308 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 308 - El valor 308 no estaría en posición 4 - Mediana diferente de 308

    Conclusión

    Para que la mediana sea 308 , N debe cumplir: 228 < N < 308

    El mayor valor posible para N es ** 307 ** (justo menor que 308 ).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
