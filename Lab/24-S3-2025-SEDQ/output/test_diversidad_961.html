Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salas de cine de un centro comercial es 320 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 339
    2. 306
    3. 319
    4. 352

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 320 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salas de cine: D, C, A, B, F, G, E
    • Sus valores son: 433, 453, 290, 271, 320, N, 365
    • La mediana del conjunto es 320
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 320 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 320 .

    Análisis de casos

    Los valores conocidos son: 290, 271, 453, 433, 365, 320

    Analicemos dónde puede ubicarse N para que la mediana sea 320:


    Caso 1: Si N es menor o igual a 271 (muy pequeño) - El valor 320 no quedaría en posición 4 - Mediana diferente de 320

    Caso 2: Si 271 < N < 320 - El valor 320 queda en posición 4 - Mediana = 320 (CORRECTO)

    Caso 3: Si N = 320 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 320 - El valor 320 no estaría en posición 4 - Mediana diferente de 320

    Conclusión

    Para que la mediana sea 320 , N debe cumplir: 271 < N < 320

    El mayor valor posible para N es ** 319 ** (justo menor que 320 ).
