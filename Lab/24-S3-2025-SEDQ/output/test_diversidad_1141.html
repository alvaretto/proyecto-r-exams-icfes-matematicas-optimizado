Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 restaurantes de un plaza de comidas es 414 y no hay dos restaurantes con el mismo número de comensales, ¿cuál es el mayor valor posible para “N”?


    1. 382
    2. 455
    3. 414
    4. 413

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 414 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 restaurantes: E, C, B, A, D
    • Sus valores son: N, 520, 526, 267, 414
    • La mediana del conjunto es 414
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 414 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 414 .

    Análisis de casos

    Los valores conocidos son: 267, 526, 520, 414

    Analicemos dónde puede ubicarse N para que la mediana sea 414:


    Caso 1: Si N es menor o igual a 267 (muy pequeño) - El valor 414 no quedaría en posición 3 - Mediana diferente de 414

    Caso 2: Si 267 < N < 414 - El valor 414 queda en posición 3 - Mediana = 414 (CORRECTO)

    Caso 3: Si N = 414 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 414 - El valor 414 no estaría en posición 3 - Mediana diferente de 414

    Conclusión

    Para que la mediana sea 414 , N debe cumplir: 267 < N < 414

    El mayor valor posible para N es ** 413 ** (justo menor que 414 ).

    2. Falso
    3. Falso
    4. Verdadero
