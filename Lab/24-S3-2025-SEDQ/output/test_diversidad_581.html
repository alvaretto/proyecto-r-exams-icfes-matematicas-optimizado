Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 canchas de tenis de un complejo deportivo es 387 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 415
    2. 386
    3. 390
    4. 387

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 387 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 canchas de tenis: A, D, C, E, B
    • Sus valores son: 289, 387, 522, N, 412
    • La mediana del conjunto es 387
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 387 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 387 .

    Análisis de casos

    Los valores conocidos son: 289, 412, 522, 387

    Analicemos dónde puede ubicarse N para que la mediana sea 387:


    Caso 1: Si N es menor o igual a 289 (muy pequeño) - El valor 387 no quedaría en posición 3 - Mediana diferente de 387

    Caso 2: Si 289 < N < 387 - El valor 387 queda en posición 3 - Mediana = 387 (CORRECTO)

    Caso 3: Si N = 387 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 387 - El valor 387 no estaría en posición 3 - Mediana diferente de 387

    Conclusión

    Para que la mediana sea 387 , N debe cumplir: 289 < N < 387

    El mayor valor posible para N es ** 386 ** (justo menor que 387 ).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
