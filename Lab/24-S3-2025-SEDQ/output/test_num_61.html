Exam 1

  1. Question

    Si la mediana de la asistencia a las 9 salas de cine de un centro comercial es 366 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 365
    2. 373
    3. 366
    4. 354

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 366 en un conjunto de 9 valores.

    Datos conocidos:

    • Tenemos 9 salas de cine: F, C, D, H, B, A, E, G, I
    • Sus valores son: 419, 250, 502, 366, 304, 218, 437, 413, N
    • La mediana del conjunto es 366
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 9 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5).

    Para que la mediana sea 366, cuando ordenemos los 9 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 366.

    Análisis de casos

    Los valores conocidos son: 218, 304, 250, 502, 437, 419, 413, 366

    Analicemos dónde puede ubicarse N para que la mediana sea 366:


    Caso 1: Si N es menor o igual a 218 (muy pequeño) - Orden: N, 218, 250, 304, 366, 413, 419, 437, 502 - Mediana = 250 diferente de 366

    Caso 2: Si 218 < N < 366 - El valor 366 queda en posición 5 - Mediana = 366 (CORRECTO)

    Caso 3: Si N = 366 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 366 - El valor 366 no estaría en posición 5 - Mediana diferente de 366

    Conclusión

    Para que la mediana sea 366 , N debe cumplir: 218 < N < 366

    El mayor valor posible para N es 365 (justo menor que 366).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
