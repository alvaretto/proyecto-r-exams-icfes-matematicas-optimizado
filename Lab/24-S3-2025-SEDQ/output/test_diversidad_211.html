Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salas de cine de un centro comercial es 340 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 359
    2. 302
    3. 365
    4. 339

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 340 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salas de cine: B, D, C, G, F, E, A
    • Sus valores son: 302, 415, 364, N, 340, 403, 239
    • La mediana del conjunto es 340
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 340 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 340 .

    Análisis de casos

    Los valores conocidos son: 239, 302, 364, 415, 403, 340

    Analicemos dónde puede ubicarse N para que la mediana sea 340:


    Caso 1: Si N es menor o igual a 239 (muy pequeño) - El valor 340 no quedaría en posición 4 - Mediana diferente de 340

    Caso 2: Si 239 < N < 340 - El valor 340 queda en posición 4 - Mediana = 340 (CORRECTO)

    Caso 3: Si N = 340 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 340 - El valor 340 no estaría en posición 4 - Mediana diferente de 340

    Conclusión

    Para que la mediana sea 340 , N debe cumplir: 239 < N < 340

    El mayor valor posible para N es ** 339 ** (justo menor que 340 ).
