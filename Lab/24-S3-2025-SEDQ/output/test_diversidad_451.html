Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 salones de un centro de convenciones es 436 y no hay dos salones con el mismo número de participantes, ¿cuál es el mayor valor posible para “N”?


    1. 392
    2. 436
    3. 435
    4. 416

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 436 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 salones: D, C, A, E, B
    • Sus valores son: 436, 513, 410, N, 473
    • La mediana del conjunto es 436
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 436 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 436 .

    Análisis de casos

    Los valores conocidos son: 410, 473, 513, 436

    Analicemos dónde puede ubicarse N para que la mediana sea 436:


    Caso 1: Si N es menor o igual a 410 (muy pequeño) - El valor 436 no quedaría en posición 3 - Mediana diferente de 436

    Caso 2: Si 410 < N < 436 - El valor 436 queda en posición 3 - Mediana = 436 (CORRECTO)

    Caso 3: Si N = 436 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 436 - El valor 436 no estaría en posición 3 - Mediana diferente de 436

    Conclusión

    Para que la mediana sea 436 , N debe cumplir: 410 < N < 436

    El mayor valor posible para N es ** 435 ** (justo menor que 436 ).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
