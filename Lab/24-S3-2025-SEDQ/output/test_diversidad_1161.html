Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salas de cine de un centro comercial es 390 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 363
    2. 389
    3. 373
    4. 390

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 390 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salas de cine: A, C, B, E, G, D, F
    • Sus valores son: 247, 484, 336, 447, N, 449, 390
    • La mediana del conjunto es 390
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 390 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 390 .

    Análisis de casos

    Los valores conocidos son: 247, 336, 484, 449, 447, 390

    Analicemos dónde puede ubicarse N para que la mediana sea 390:


    Caso 1: Si N es menor o igual a 247 (muy pequeño) - El valor 390 no quedaría en posición 4 - Mediana diferente de 390

    Caso 2: Si 247 < N < 390 - El valor 390 queda en posición 4 - Mediana = 390 (CORRECTO)

    Caso 3: Si N = 390 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 390 - El valor 390 no estaría en posición 4 - Mediana diferente de 390

    Conclusión

    Para que la mediana sea 390 , N debe cumplir: 247 < N < 390

    El mayor valor posible para N es ** 389 ** (justo menor que 390 ).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
