Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 restaurantes de un plaza de comidas es 357 y no hay dos restaurantes con el mismo número de comensales, ¿cuál es el mayor valor posible para “N”?


    1. 357
    2. 338
    3. 393
    4. 356

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 357 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 restaurantes: D, B, A, G, E, F, C
    • Sus valores son: 431, 226, 308, N, 503, 357, 381
    • La mediana del conjunto es 357
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 357 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 357 .

    Análisis de casos

    Los valores conocidos son: 308, 226, 381, 431, 503, 357

    Analicemos dónde puede ubicarse N para que la mediana sea 357:


    Caso 1: Si N es menor o igual a 226 (muy pequeño) - El valor 357 no quedaría en posición 4 - Mediana diferente de 357

    Caso 2: Si 226 < N < 357 - El valor 357 queda en posición 4 - Mediana = 357 (CORRECTO)

    Caso 3: Si N = 357 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 357 - El valor 357 no estaría en posición 4 - Mediana diferente de 357

    Conclusión

    Para que la mediana sea 357 , N debe cumplir: 226 < N < 357

    El mayor valor posible para N es ** 356 ** (justo menor que 357 ).


    1. Falso
    2. Falso
    3. Falso
    4. Verdadero
