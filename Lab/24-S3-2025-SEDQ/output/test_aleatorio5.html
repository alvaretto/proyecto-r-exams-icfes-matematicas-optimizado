Exam 5

  1. Question

    Si la mediana de la asistencia a las 8 canchas de tenis de un complejo deportivo es 319 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 305
    2. 318
    3. 325
    4. 319

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 319 en un conjunto de 8 valores.

    Datos conocidos:

    • Tenemos 8 canchas de tenis: C, B, F, D, G, A, E, H
    • Sus valores son: 389, 245, 374, 443, 319, 240, 387, N
    • La mediana del conjunto es 319
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 8 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4).

    Para que la mediana sea 319, cuando ordenemos los 8 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 319.

    Análisis de casos

    Los valores conocidos son: 240, 245, 389, 443, 387, 374, 319

    Analicemos dónde puede ubicarse N para que la mediana sea 319:


    Caso 1: Si N es menor o igual a 240 (muy pequeño) - Orden: N, 240, 245, 319, 374, 387, 389, 443 - Mediana = 245 diferente de 319

    Caso 2: Si 240 < N < 319 - El valor 319 queda en posición 4 - Mediana = 319 (CORRECTO)

    Caso 3: Si N = 319 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 319 - El valor 319 no estaría en posición 4 - Mediana diferente de 319

    Conclusión

    Para que la mediana sea 319 , N debe cumplir: 240 < N < 319

    El mayor valor posible para N es 318 (justo menor que 319).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
