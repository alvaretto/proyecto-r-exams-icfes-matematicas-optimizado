Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 restaurantes de un plaza de comidas es 451 y no hay dos restaurantes con el mismo número de comensales, ¿cuál es el mayor valor posible para “N”?


    1. 474
    2. 476
    3. 451
    4. 450

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 451 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 restaurantes: D, G, A, B, E, C, F
    • Sus valores son: 566, N, 380, 337, 543, 588, 451
    • La mediana del conjunto es 451
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 451 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 451 .

    Análisis de casos

    Los valores conocidos son: 380, 337, 588, 566, 543, 451

    Analicemos dónde puede ubicarse N para que la mediana sea 451:


    Caso 1: Si N es menor o igual a 337 (muy pequeño) - El valor 451 no quedaría en posición 4 - Mediana diferente de 451

    Caso 2: Si 337 < N < 451 - El valor 451 queda en posición 4 - Mediana = 451 (CORRECTO)

    Caso 3: Si N = 451 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 451 - El valor 451 no estaría en posición 4 - Mediana diferente de 451

    Conclusión

    Para que la mediana sea 451 , N debe cumplir: 337 < N < 451

    El mayor valor posible para N es ** 450 ** (justo menor que 451 ).


    1. Falso
    2. Falso
    3. Falso
    4. Verdadero
