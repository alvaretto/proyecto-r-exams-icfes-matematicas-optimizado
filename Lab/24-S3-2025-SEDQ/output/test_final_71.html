Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salas de cine de un centro comercial es 497 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 502
    2. 496
    3. 486
    4. 497

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 497 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salas de cine: E, B, A, D, C, F, G
    • Sus valores son: 569, 441, 390, 634, 558, 497, N
    • La mediana del conjunto es 497
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 497 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 497 .

    Análisis de casos

    Los valores conocidos son: 390, 441, 558, 634, 569, 497

    Analicemos dónde puede ubicarse N para que la mediana sea 497:


    Caso 1: Si N es menor o igual a 390 (muy pequeño) - El valor 497 no quedaría en posición 4 - Mediana diferente de 497

    Caso 2: Si 390 < N < 497 - El valor 497 queda en posición 4 - Mediana = 497 (CORRECTO)

    Caso 3: Si N = 497 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 497 - El valor 497 no estaría en posición 4 - Mediana diferente de 497

    Conclusión

    Para que la mediana sea 497 , N debe cumplir: 390 < N < 497

    El mayor valor posible para N es 496 (justo menor que 497).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
