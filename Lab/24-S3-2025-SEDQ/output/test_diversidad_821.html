Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 canchas de tenis de un complejo deportivo es 333 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 300
    2. 337
    3. 332
    4. 360

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 333 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 canchas de tenis: A, B, G, F, E, D, C
    • Sus valores son: 243, 309, N, 333, 476, 398, 415
    • La mediana del conjunto es 333
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 333 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 333 .

    Análisis de casos

    Los valores conocidos son: 243, 309, 415, 398, 476, 333

    Analicemos dónde puede ubicarse N para que la mediana sea 333:


    Caso 1: Si N es menor o igual a 243 (muy pequeño) - El valor 333 no quedaría en posición 4 - Mediana diferente de 333

    Caso 2: Si 243 < N < 333 - El valor 333 queda en posición 4 - Mediana = 333 (CORRECTO)

    Caso 3: Si N = 333 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 333 - El valor 333 no estaría en posición 4 - Mediana diferente de 333

    Conclusión

    Para que la mediana sea 333 , N debe cumplir: 243 < N < 333

    El mayor valor posible para N es ** 332 ** (justo menor que 333 ).

    2. Falso
