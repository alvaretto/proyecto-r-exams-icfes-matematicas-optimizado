Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 salones de un centro de convenciones es 434 y no hay dos salones con el mismo número de participantes, ¿cuál es el mayor valor posible para “N”?


    1. 434
    2. 433
    3. 477
    4. 391

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 434 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 salones: B, C, A, D, E
    • Sus valores son: 561, 456, 343, 434, N
    • La mediana del conjunto es 434
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 434 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 434 .

    Análisis de casos

    Los valores conocidos son: 343, 561, 456, 434

    Analicemos dónde puede ubicarse N para que la mediana sea 434:


    Caso 1: Si N es menor o igual a 343 (muy pequeño) - El valor 434 no quedaría en posición 3 - Mediana diferente de 434

    Caso 2: Si 343 < N < 434 - El valor 434 queda en posición 3 - Mediana = 434 (CORRECTO)

    Caso 3: Si N = 434 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 434 - El valor 434 no estaría en posición 3 - Mediana diferente de 434

    Conclusión

    Para que la mediana sea 434 , N debe cumplir: 343 < N < 434

    El mayor valor posible para N es ** 433 ** (justo menor que 434 ).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
