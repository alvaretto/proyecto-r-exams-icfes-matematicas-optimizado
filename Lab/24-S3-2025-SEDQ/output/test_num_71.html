Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salones de un centro de convenciones es 426 y no hay dos salones con el mismo número de participantes, ¿cuál es el mayor valor posible para “N”?


    1. 417
    2. 433
    3. 426
    4. 425

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 426 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salones: B, F, E, C, D, A, G
    • Sus valores son: 385, 426, 534, 521, 486, 350, N
    • La mediana del conjunto es 426
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4).

    Para que la mediana sea 426, cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 426.

    Análisis de casos

    Los valores conocidos son: 350, 385, 521, 486, 534, 426

    Analicemos dónde puede ubicarse N para que la mediana sea 426:


    Caso 1: Si N es menor o igual a 350 (muy pequeño) - Orden: N, 350, 385, 426, 486, 521, 534 - Mediana = 385 diferente de 426

    Caso 2: Si 350 < N < 426 - El valor 426 queda en posición 4 - Mediana = 426 (CORRECTO)

    Caso 3: Si N = 426 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 426 - El valor 426 no estaría en posición 4 - Mediana diferente de 426

    Conclusión

    Para que la mediana sea 426 , N debe cumplir: 350 < N < 426

    El mayor valor posible para N es 425 (justo menor que 426).


    1. Falso
    2. Falso
    3. Falso
    4. Verdadero
