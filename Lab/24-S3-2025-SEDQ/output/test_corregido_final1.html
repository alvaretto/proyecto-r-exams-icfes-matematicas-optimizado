Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 salas de cine de un centro comercial es 381 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 343
    2. 393
    3. 398
    4. 380

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 381 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 salas de cine: E, C, A, B, D
    • Sus valores son: N, 529, 259, 519, 381
    • La mediana del conjunto es 381
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 381 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 381 .

    Análisis de casos

    Los valores conocidos son: 259, 519, 529, 381

    Analicemos dónde puede ubicarse N para que la mediana sea 381:


    Caso 1: Si N es menor o igual a 259 (muy pequeño) - El valor 381 no quedaría en posición 3 - Mediana diferente de 381

    Caso 2: Si 259 < N < 381 - El valor 381 queda en posición 3 - Mediana = 381 (CORRECTO)

    Caso 3: Si N = 381 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 381 - El valor 381 no estaría en posición 3 - Mediana diferente de 381

    Conclusión

    Para que la mediana sea 381 , N debe cumplir: 259 < N < 381

    El mayor valor posible para N es ** 380 ** (justo menor que 381 ).
