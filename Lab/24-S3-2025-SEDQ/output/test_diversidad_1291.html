Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 canchas de tenis de un complejo deportivo es 386 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 361
    2. 393
    3. 385
    4. 347

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 386 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 canchas de tenis: C, A, B, D, E, F, G
    • Sus valores son: 462, 275, 266, 467, 453, 386, N
    • La mediana del conjunto es 386
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 386 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 386 .

    Análisis de casos

    Los valores conocidos son: 275, 266, 462, 467, 453, 386

    Analicemos dónde puede ubicarse N para que la mediana sea 386:


    Caso 1: Si N es menor o igual a 266 (muy pequeño) - El valor 386 no quedaría en posición 4 - Mediana diferente de 386

    Caso 2: Si 266 < N < 386 - El valor 386 queda en posición 4 - Mediana = 386 (CORRECTO)

    Caso 3: Si N = 386 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 386 - El valor 386 no estaría en posición 4 - Mediana diferente de 386

    Conclusión

    Para que la mediana sea 386 , N debe cumplir: 266 < N < 386

    El mayor valor posible para N es ** 385 ** (justo menor que 386 ).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
