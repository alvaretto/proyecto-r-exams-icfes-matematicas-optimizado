Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salas de cine de un centro comercial es 386 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 386
    2. 386
    3. 371
    4. 385

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 386 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salas de cine: E, C, A, D, F, B, G
    • Sus valores son: 455, 427, 280, 470, 386, 255, N
    • La mediana del conjunto es 386
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 386 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 386 .

    Análisis de casos

    Los valores conocidos son: 280, 255, 427, 470, 455, 386

    Analicemos dónde puede ubicarse N para que la mediana sea 386:


    Caso 1: Si N es menor o igual a 255 (muy pequeño) - El valor 386 no quedaría en posición 4 - Mediana diferente de 386

    Caso 2: Si 255 < N < 386 - El valor 386 queda en posición 4 - Mediana = 386 (CORRECTO)

    Caso 3: Si N = 386 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 386 - El valor 386 no estaría en posición 4 - Mediana diferente de 386

    Conclusión

    Para que la mediana sea 386 , N debe cumplir: 255 < N < 386

    El mayor valor posible para N es 385 (justo menor que 386).


    1. Falso
    2. Falso
    3. Falso
    4. Verdadero
