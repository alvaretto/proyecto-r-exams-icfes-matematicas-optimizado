Exam 3

  1. Question

    Si la mediana de la asistencia a las 7 salas de cine de un centro comercial es 316 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 300
    2. 315
    3. 316
    4. 324

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 316 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salas de cine: A, D, B, C, F, E, G
    • Sus valores son: 202, 419, 258, 364, 316, 386, N
    • La mediana del conjunto es 316
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4).

    Para que la mediana sea 316, cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 316.

    Análisis de casos

    Los valores conocidos son: 202, 258, 364, 419, 386, 316

    Analicemos dónde puede ubicarse N para que la mediana sea 316:


    Caso 1: Si N es menor o igual a 202 (muy pequeño) - Orden: N, 202, 258, 316, 364, 386, 419 - Mediana = 258 diferente de 316

    Caso 2: Si 202 < N < 316 - El valor 316 queda en posición 4 - Mediana = 316 (CORRECTO)

    Caso 3: Si N = 316 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 316 - El valor 316 no estaría en posición 4 - Mediana diferente de 316

    Conclusión

    Para que la mediana sea 316 , N debe cumplir: 202 < N < 316

    El mayor valor posible para N es 315 (justo menor que 316).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
