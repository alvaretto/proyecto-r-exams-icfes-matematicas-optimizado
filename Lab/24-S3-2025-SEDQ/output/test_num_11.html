Exam 1

  1. Question

    Si la mediana de la asistencia a las 9 atracciones de un parque temático es 359 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 360
    2. 359
    3. 358
    4. 352

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 359 en un conjunto de 9 valores.

    Datos conocidos:

    • Tenemos 9 atracciones: D, G, H, E, F, B, A, C, I
    • Sus valores son: 457, 474, 359, 483, 438, 228, 232, 285, N
    • La mediana del conjunto es 359
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 9 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5).

    Para que la mediana sea 359, cuando ordenemos los 9 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 359.

    Análisis de casos

    Los valores conocidos son: 232, 228, 285, 457, 483, 438, 474, 359

    Analicemos dónde puede ubicarse N para que la mediana sea 359:


    Caso 1: Si N es menor o igual a 228 (muy pequeño) - Orden: N, 228, 232, 285, 359, 438, 457, 474, 483 - Mediana = 232 diferente de 359

    Caso 2: Si 228 < N < 359 - El valor 359 queda en posición 5 - Mediana = 359 (CORRECTO)

    Caso 3: Si N = 359 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 359 - El valor 359 no estaría en posición 5 - Mediana diferente de 359

    Conclusión

    Para que la mediana sea 359 , N debe cumplir: 228 < N < 359

    El mayor valor posible para N es 358 (justo menor que 359).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
