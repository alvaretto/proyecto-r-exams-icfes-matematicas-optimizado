Exam 3

  1. Question

    Si la mediana de la asistencia a las 9 salas de cine de un centro comercial es 344 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 325
    2. 344
    3. 310
    4. 343

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 344 en un conjunto de 9 valores.

    Datos conocidos:

    • Tenemos 9 salas de cine: G, C, B, I, A, F, H, E, D
    • Sus valores son: 474, 264, 306, N, 261, 376, 344, 369, 405
    • La mediana del conjunto es 344
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 9 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5 ).

    Para que la mediana sea 344 , cuando ordenemos los 9 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 344 .

    Análisis de casos

    Los valores conocidos son: 261, 306, 264, 405, 369, 376, 474, 344

    Analicemos dónde puede ubicarse N para que la mediana sea 344:


    Caso 1: Si N es menor o igual a 261 (muy pequeño) - El valor 344 no quedaría en posición 5 - Mediana diferente de 344

    Caso 2: Si 261 < N < 344 - El valor 344 queda en posición 5 - Mediana = 344 (CORRECTO)

    Caso 3: Si N = 344 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 344 - El valor 344 no estaría en posición 5 - Mediana diferente de 344

    Conclusión

    Para que la mediana sea 344 , N debe cumplir: 261 < N < 344

    El mayor valor posible para N es ** 343 ** (justo menor que 344 ).
