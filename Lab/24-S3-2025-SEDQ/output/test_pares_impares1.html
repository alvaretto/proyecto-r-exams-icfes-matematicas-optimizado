Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 auditorios de un centro cultural es 496 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 496
    2. 484
    3. 496
    4. 495

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 496 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 auditorios: D, C, A, B, E
    • Sus valores son: 496, 624, 401, 586, N
    • La mediana del conjunto es 496
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 496 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 496 .

    Análisis de casos

    Los valores conocidos son: 401, 586, 624, 496

    Analicemos dónde puede ubicarse N para que la mediana sea 496:


    Caso 1: Si N es menor o igual a 401 (muy pequeño) - El valor 496 no quedaría en posición 3 - Mediana diferente de 496

    Caso 2: Si 401 < N < 496 - El valor 496 queda en posición 3 - Mediana = 496 (CORRECTO)

    Caso 3: Si N = 496 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 496 - El valor 496 no estaría en posición 3 - Mediana diferente de 496

    Conclusión

    Para que la mediana sea 496 , N debe cumplir: 401 < N < 496

    El mayor valor posible para N es ** 495 ** (justo menor que 496 ).

    2. Falso
    3. Falso
    4. Verdadero
