Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 383 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 382
    2. 377
    3. 383
    4. 386

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 383 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: B, D, C, A, E
    • Sus valores son: 464, 383, 408, 257, N
    • La mediana del conjunto es 383
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 383 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 383 .

    Análisis de casos

    Los valores conocidos son: 257, 464, 408, 383

    Analicemos dónde puede ubicarse N para que la mediana sea 383:


    Caso 1: Si N es menor o igual a 257 (muy pequeño) - El valor 383 no quedaría en posición 3 - Mediana diferente de 383

    Caso 2: Si 257 < N < 383 - El valor 383 queda en posición 3 - Mediana = 383 (CORRECTO)

    Caso 3: Si N = 383 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 383 - El valor 383 no estaría en posición 3 - Mediana diferente de 383

    Conclusión

    Para que la mediana sea 383 , N debe cumplir: 257 < N < 383

    El mayor valor posible para N es 382 (justo menor que 383).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
