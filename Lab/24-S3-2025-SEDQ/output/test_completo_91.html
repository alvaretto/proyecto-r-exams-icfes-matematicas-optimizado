Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salones de un centro de convenciones es 476 y no hay dos salones con el mismo número de participantes, ¿cuál es el mayor valor posible para “N”?


    1. 482
    2. 475
    3. 476
    4. 460

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 476 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salones: C, D, B, E, A, F, G
    • Sus valores son: 606, 502, 330, 511, 432, 476, N
    • La mediana del conjunto es 476
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 476 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 476 .

    Análisis de casos

    Los valores conocidos son: 432, 330, 606, 502, 511, 476

    Analicemos dónde puede ubicarse N para que la mediana sea 476:


    Caso 1: Si N es menor o igual a 330 (muy pequeño) - El valor 476 no quedaría en posición 4 - Mediana diferente de 476

    Caso 2: Si 330 < N < 476 - El valor 476 queda en posición 4 - Mediana = 476 (CORRECTO)

    Caso 3: Si N = 476 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 476 - El valor 476 no estaría en posición 4 - Mediana diferente de 476

    Conclusión

    Para que la mediana sea 476 , N debe cumplir: 330 < N < 476

    El mayor valor posible para N es ** 475 ** (justo menor que 476 ).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
