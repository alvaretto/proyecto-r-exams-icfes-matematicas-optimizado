Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 auditorios de un centro cultural es 331 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 333
    2. 330
    3. 314
    4. 347

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 331 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 auditorios: B, A, D, C, G, F, E
    • Sus valores son: 294, 268, 364, 393, N, 331, 390
    • La mediana del conjunto es 331
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 331 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 331 .

    Análisis de casos

    Los valores conocidos son: 268, 294, 393, 364, 390, 331

    Analicemos dónde puede ubicarse N para que la mediana sea 331:


    Caso 1: Si N es menor o igual a 268 (muy pequeño) - El valor 331 no quedaría en posición 4 - Mediana diferente de 331

    Caso 2: Si 268 < N < 331 - El valor 331 queda en posición 4 - Mediana = 331 (CORRECTO)

    Caso 3: Si N = 331 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 331 - El valor 331 no estaría en posición 4 - Mediana diferente de 331

    Conclusión

    Para que la mediana sea 331 , N debe cumplir: 268 < N < 331

    El mayor valor posible para N es ** 330 ** (justo menor que 331 ).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
