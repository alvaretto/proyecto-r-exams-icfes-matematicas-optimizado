Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 auditorios de un centro cultural es 366 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 365
    2. 370
    3. 338
    4. 386

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 366 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 auditorios: G, E, F, C, D, A, B
    • Sus valores son: N, 493, 366, 436, 505, 216, 338
    • La mediana del conjunto es 366
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 366 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 366 .

    Análisis de casos

    Los valores conocidos son: 216, 338, 436, 505, 493, 366

    Analicemos dónde puede ubicarse N para que la mediana sea 366:


    Caso 1: Si N es menor o igual a 216 (muy pequeño) - El valor 366 no quedaría en posición 4 - Mediana diferente de 366

    Caso 2: Si 216 < N < 366 - El valor 366 queda en posición 4 - Mediana = 366 (CORRECTO)

    Caso 3: Si N = 366 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 366 - El valor 366 no estaría en posición 4 - Mediana diferente de 366

    Conclusión

    Para que la mediana sea 366 , N debe cumplir: 216 < N < 366

    El mayor valor posible para N es ** 365 ** (justo menor que 366 ).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
