Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 auditorios de un centro cultural es 351 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 334
    2. 350
    3. 351
    4. 316

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 351 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 auditorios: G, A, B, F, D, E, C
    • Sus valores son: N, 243, 281, 351, 485, 490, 486
    • La mediana del conjunto es 351
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 351 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 351 .

    Análisis de casos

    Los valores conocidos son: 243, 281, 486, 485, 490, 351

    Analicemos dónde puede ubicarse N para que la mediana sea 351:


    Caso 1: Si N es menor o igual a 243 (muy pequeño) - El valor 351 no quedaría en posición 4 - Mediana diferente de 351

    Caso 2: Si 243 < N < 351 - El valor 351 queda en posición 4 - Mediana = 351 (CORRECTO)

    Caso 3: Si N = 351 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 351 - El valor 351 no estaría en posición 4 - Mediana diferente de 351

    Conclusión

    Para que la mediana sea 351 , N debe cumplir: 243 < N < 351

    El mayor valor posible para N es ** 350 ** (justo menor que 351 ).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
