Exam 4

  1. Question

    Si la mediana de la asistencia a las 9 salas de cine de un centro comercial es 396 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 400
    2. 387
    3. 395
    4. 396

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 396 en un conjunto de 9 valores.

    Datos conocidos:

    • Tenemos 9 salas de cine: B, E, A, G, D, H, C, F, I
    • Sus valores son: 270, 516, 360, 536, 508, 396, 249, 416, N
    • La mediana del conjunto es 396
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 9 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5).

    Para que la mediana sea 396, cuando ordenemos los 9 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 396.

    Análisis de casos

    Los valores conocidos son: 360, 270, 249, 508, 516, 416, 536, 396

    Analicemos dónde puede ubicarse N para que la mediana sea 396:


    Caso 1: Si N es menor o igual a 249 (muy pequeño) - Orden: N, 249, 270, 360, 396, 416, 508, 516, 536 - Mediana = 270 diferente de 396

    Caso 2: Si 249 < N < 396 - El valor 396 queda en posición 5 - Mediana = 396 (CORRECTO)

    Caso 3: Si N = 396 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 396 - El valor 396 no estaría en posición 5 - Mediana diferente de 396

    Conclusión

    Para que la mediana sea 396 , N debe cumplir: 249 < N < 396

    El mayor valor posible para N es 395 (justo menor que 396).
