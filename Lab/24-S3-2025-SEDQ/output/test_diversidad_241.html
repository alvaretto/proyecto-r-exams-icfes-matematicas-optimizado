Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 canchas de tenis de un complejo deportivo es 486 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 535
    2. 479
    3. 437
    4. 485

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 486 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 canchas de tenis: G, F, A, B, D, E, C
    • Sus valores son: N, 486, 385, 437, 509, 560, 535
    • La mediana del conjunto es 486
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 486 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 486 .

    Análisis de casos

    Los valores conocidos son: 385, 437, 535, 509, 560, 486

    Analicemos dónde puede ubicarse N para que la mediana sea 486:


    Caso 1: Si N es menor o igual a 385 (muy pequeño) - El valor 486 no quedaría en posición 4 - Mediana diferente de 486

    Caso 2: Si 385 < N < 486 - El valor 486 queda en posición 4 - Mediana = 486 (CORRECTO)

    Caso 3: Si N = 486 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 486 - El valor 486 no estaría en posición 4 - Mediana diferente de 486

    Conclusión

    Para que la mediana sea 486 , N debe cumplir: 385 < N < 486

    El mayor valor posible para N es ** 485 ** (justo menor que 486 ).
