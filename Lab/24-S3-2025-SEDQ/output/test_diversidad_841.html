Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 401 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 400
    2. 441
    3. 389
    4. 372

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 401 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: E, B, D, A, C
    • Sus valores son: N, 497, 401, 297, 483
    • La mediana del conjunto es 401
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 401 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 401 .

    Análisis de casos

    Los valores conocidos son: 297, 497, 483, 401

    Analicemos dónde puede ubicarse N para que la mediana sea 401:


    Caso 1: Si N es menor o igual a 297 (muy pequeño) - El valor 401 no quedaría en posición 3 - Mediana diferente de 401

    Caso 2: Si 297 < N < 401 - El valor 401 queda en posición 3 - Mediana = 401 (CORRECTO)

    Caso 3: Si N = 401 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 401 - El valor 401 no estaría en posición 3 - Mediana diferente de 401

    Conclusión

    Para que la mediana sea 401 , N debe cumplir: 297 < N < 401

    El mayor valor posible para N es ** 400 ** (justo menor que 401 ).
