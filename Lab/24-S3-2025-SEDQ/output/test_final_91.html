Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 atracciones de un parque temático es 474 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 461
    2. 479
    3. 473
    4. 474

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 474 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 atracciones: F, A, E, B, D, C, G
    • Sus valores son: 474, 381, 543, 368, 533, 617, N
    • La mediana del conjunto es 474
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 474 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 474 .

    Análisis de casos

    Los valores conocidos son: 381, 368, 617, 533, 543, 474

    Analicemos dónde puede ubicarse N para que la mediana sea 474:


    Caso 1: Si N es menor o igual a 368 (muy pequeño) - El valor 474 no quedaría en posición 4 - Mediana diferente de 474

    Caso 2: Si 368 < N < 474 - El valor 474 queda en posición 4 - Mediana = 474 (CORRECTO)

    Caso 3: Si N = 474 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 474 - El valor 474 no estaría en posición 4 - Mediana diferente de 474

    Conclusión

    Para que la mediana sea 474 , N debe cumplir: 368 < N < 474

    El mayor valor posible para N es 473 (justo menor que 474).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
