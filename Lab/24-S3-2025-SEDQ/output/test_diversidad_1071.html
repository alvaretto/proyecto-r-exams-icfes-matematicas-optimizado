Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 auditorios de un centro cultural es 380 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 342
    2. 345
    3. 380
    4. 379

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 380 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 auditorios: G, D, C, E, B, F, A
    • Sus valores son: N, 492, 434, 472, 321, 380, 343
    • La mediana del conjunto es 380
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 380 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 380 .

    Análisis de casos

    Los valores conocidos son: 343, 321, 434, 492, 472, 380

    Analicemos dónde puede ubicarse N para que la mediana sea 380:


    Caso 1: Si N es menor o igual a 321 (muy pequeño) - El valor 380 no quedaría en posición 4 - Mediana diferente de 380

    Caso 2: Si 321 < N < 380 - El valor 380 queda en posición 4 - Mediana = 380 (CORRECTO)

    Caso 3: Si N = 380 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 380 - El valor 380 no estaría en posición 4 - Mediana diferente de 380

    Conclusión

    Para que la mediana sea 380 , N debe cumplir: 321 < N < 380

    El mayor valor posible para N es ** 379 ** (justo menor que 380 ).
