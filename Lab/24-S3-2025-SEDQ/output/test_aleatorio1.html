Exam 1

  1. Question

    Si la mediana de la asistencia a las 10 auditorios de un centro cultural es 363 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 362
    2. 355
    3. 368
    4. 363

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 363 en un conjunto de 10 valores.

    Datos conocidos:

    • Tenemos 10 auditorios: G, E, A, F, D, I, C, B, H, J
    • Sus valores son: 417, 430, 278, 480, 493, 363, 292, 313, 456, N
    • La mediana del conjunto es 363
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 10 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5).

    Para que la mediana sea 363, cuando ordenemos los 10 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 363.

    Análisis de casos

    Los valores conocidos son: 278, 313, 292, 493, 430, 480, 417, 456, 363

    Analicemos dónde puede ubicarse N para que la mediana sea 363:


    Caso 1: Si N es menor o igual a 278 (muy pequeño) - Orden: N, 278, 292, 313, 363, 417, 430, 456, 480, 493 - Mediana = 292 diferente de 363

    Caso 2: Si 278 < N < 363 - El valor 363 queda en posición 5 - Mediana = 363 (CORRECTO)

    Caso 3: Si N = 363 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 363 - El valor 363 no estaría en posición 5 - Mediana diferente de 363

    Conclusión

    Para que la mediana sea 363 , N debe cumplir: 278 < N < 363

    El mayor valor posible para N es 362 (justo menor que 363).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
