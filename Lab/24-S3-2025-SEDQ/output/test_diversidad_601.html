Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 salones de un centro de convenciones es 323 y no hay dos salones con el mismo número de participantes, ¿cuál es el mayor valor posible para “N”?


    1. 291
    2. 288
    3. 289
    4. 322

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 323 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 salones: F, C, D, A, E, B, G
    • Sus valores son: 323, 378, 441, 212, 469, 255, N
    • La mediana del conjunto es 323
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 323 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 323 .

    Análisis de casos

    Los valores conocidos son: 212, 255, 378, 441, 469, 323

    Analicemos dónde puede ubicarse N para que la mediana sea 323:


    Caso 1: Si N es menor o igual a 212 (muy pequeño) - El valor 323 no quedaría en posición 4 - Mediana diferente de 323

    Caso 2: Si 212 < N < 323 - El valor 323 queda en posición 4 - Mediana = 323 (CORRECTO)

    Caso 3: Si N = 323 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 323 - El valor 323 no estaría en posición 4 - Mediana diferente de 323

    Conclusión

    Para que la mediana sea 323 , N debe cumplir: 212 < N < 323

    El mayor valor posible para N es ** 322 ** (justo menor que 323 ).

    3. Falso
    4. Verdadero
