Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 canchas de tenis de un complejo deportivo es 304 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 287
    2. 309
    3. 274
    4. 303

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 304 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 canchas de tenis: G, E, B, A, F, C, D
    • Sus valores son: N, 434, 197, 227, 304, 448, 367
    • La mediana del conjunto es 304
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 304 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 304 .

    Análisis de casos

    Los valores conocidos son: 227, 197, 448, 367, 434, 304

    Analicemos dónde puede ubicarse N para que la mediana sea 304:


    Caso 1: Si N es menor o igual a 197 (muy pequeño) - El valor 304 no quedaría en posición 4 - Mediana diferente de 304

    Caso 2: Si 197 < N < 304 - El valor 304 queda en posición 4 - Mediana = 304 (CORRECTO)

    Caso 3: Si N = 304 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 304 - El valor 304 no estaría en posición 4 - Mediana diferente de 304

    Conclusión

    Para que la mediana sea 304 , N debe cumplir: 197 < N < 304

    El mayor valor posible para N es ** 303 ** (justo menor que 304 ).
