Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 canchas de tenis de un complejo deportivo es 308 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 308
    2. 308
    3. 307
    4. 294

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 308 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 canchas de tenis: A, C, D, B, E
    • Sus valores son: 160, 426, 308, 338, N
    • La mediana del conjunto es 308
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3).

    Para que la mediana sea 308, cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 308.

    Análisis de casos

    Los valores conocidos son: 160, 338, 426, 308

    Analicemos dónde puede ubicarse N para que la mediana sea 308:


    Caso 1: Si N es menor o igual a 160 (muy pequeño) - Orden: N, 160, 308, 338, 426 - Mediana = 308 diferente de 308

    Caso 2: Si 160 < N < 308 - El valor 308 queda en posición 3 - Mediana = 308 (CORRECTO)

    Caso 3: Si N = 308 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 308 - El valor 308 no estaría en posición 3 - Mediana diferente de 308

    Conclusión

    Para que la mediana sea 308 , N debe cumplir: 160 < N < 308

    El mayor valor posible para N es 307 (justo menor que 308).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
