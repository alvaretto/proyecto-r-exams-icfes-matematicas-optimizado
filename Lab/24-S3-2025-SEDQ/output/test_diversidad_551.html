Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 319 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 318
    2. 301
    3. 282
    4. 337

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 319 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: A, E, D, C, B
    • Sus valores son: 282, N, 319, 354, 421
    • La mediana del conjunto es 319
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 319 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 319 .

    Análisis de casos

    Los valores conocidos son: 282, 421, 354, 319

    Analicemos dónde puede ubicarse N para que la mediana sea 319:


    Caso 1: Si N es menor o igual a 282 (muy pequeño) - El valor 319 no quedaría en posición 3 - Mediana diferente de 319

    Caso 2: Si 282 < N < 319 - El valor 319 queda en posición 3 - Mediana = 319 (CORRECTO)

    Caso 3: Si N = 319 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 319 - El valor 319 no estaría en posición 3 - Mediana diferente de 319

    Conclusión

    Para que la mediana sea 319 , N debe cumplir: 282 < N < 319

    El mayor valor posible para N es ** 318 ** (justo menor que 319 ).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
