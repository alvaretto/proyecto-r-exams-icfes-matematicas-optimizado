Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 410 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 423
    2. 451
    3. 369
    4. 409

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 410 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: E, D, C, B, A
    • Sus valores son: N, 410, 512, 521, 289
    • La mediana del conjunto es 410
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 410 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 410 .

    Análisis de casos

    Los valores conocidos son: 289, 521, 512, 410

    Analicemos dónde puede ubicarse N para que la mediana sea 410:


    Caso 1: Si N es menor o igual a 289 (muy pequeño) - El valor 410 no quedaría en posición 3 - Mediana diferente de 410

    Caso 2: Si 289 < N < 410 - El valor 410 queda en posición 3 - Mediana = 410 (CORRECTO)

    Caso 3: Si N = 410 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 410 - El valor 410 no estaría en posición 3 - Mediana diferente de 410

    Conclusión

    Para que la mediana sea 410 , N debe cumplir: 289 < N < 410

    El mayor valor posible para N es ** 409 ** (justo menor que 410 ).
