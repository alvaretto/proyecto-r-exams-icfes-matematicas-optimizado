Exam 3

  1. Question

    Si la mediana de la asistencia a las 7 auditorios de un centro cultural es 315 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 316
    2. 303
    3. 314
    4. 315

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 315 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 auditorios: C, A, D, B, F, E, G
    • Sus valores son: 360, 266, 415, 273, 315, 350, N
    • La mediana del conjunto es 315
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 315 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 315 .

    Análisis de casos

    Los valores conocidos son: 266, 273, 360, 415, 350, 315

    Analicemos dónde puede ubicarse N para que la mediana sea 315:


    Caso 1: Si N es menor o igual a 266 (muy pequeño) - El valor 315 no quedaría en posición 4 - Mediana diferente de 315

    Caso 2: Si 266 < N < 315 - El valor 315 queda en posición 4 - Mediana = 315 (CORRECTO)

    Caso 3: Si N = 315 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 315 - El valor 315 no estaría en posición 4 - Mediana diferente de 315

    Conclusión

    Para que la mediana sea 315 , N debe cumplir: 266 < N < 315

    El mayor valor posible para N es 314 (justo menor que 315).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
