Exam 1

  1. Question

    Si la mediana de la asistencia a las 6 salas de cine de un centro comercial es 328 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 332
    2. 318
    3. 327
    4. 328

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 328 en un conjunto de 6 valores.

    Datos conocidos:

    • Tenemos 6 salas de cine: D, C, E, A, B, F
    • Sus valores son: 442, 437, 328, 295, 389, N
    • La mediana del conjunto es 328
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 6 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3).

    Para que la mediana sea 328, cuando ordenemos los 6 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 328.

    Análisis de casos

    Los valores conocidos son: 295, 389, 437, 442, 328

    Analicemos dónde puede ubicarse N para que la mediana sea 328:


    Caso 1: Si N es menor o igual a 295 (muy pequeño) - Orden: N, 295, 328, 389, 437, 442 - Mediana = 328 diferente de 328

    Caso 2: Si 295 < N < 328 - El valor 328 queda en posición 3 - Mediana = 328 (CORRECTO)

    Caso 3: Si N = 328 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 328 - El valor 328 no estaría en posición 3 - Mediana diferente de 328

    Conclusión

    Para que la mediana sea 328 , N debe cumplir: 295 < N < 328

    El mayor valor posible para N es 327 (justo menor que 328).


    1. Falso
    2. Falso
    3. Verdadero
    4. Falso
