Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 restaurantes de un plaza de comidas es 467 y no hay dos restaurantes con el mismo número de comensales, ¿cuál es el mayor valor posible para “N”?


    1. 487
    2. 466
    3. 467
    4. 446

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 467 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 restaurantes: F, C, B, D, A, E, G
    • Sus valores son: 467, 488, 418, 519, 382, 575, N
    • La mediana del conjunto es 467
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 467 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 467 .

    Análisis de casos

    Los valores conocidos son: 382, 418, 488, 519, 575, 467

    Analicemos dónde puede ubicarse N para que la mediana sea 467:


    Caso 1: Si N es menor o igual a 382 (muy pequeño) - El valor 467 no quedaría en posición 4 - Mediana diferente de 467

    Caso 2: Si 382 < N < 467 - El valor 467 queda en posición 4 - Mediana = 467 (CORRECTO)

    Caso 3: Si N = 467 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 467 - El valor 467 no estaría en posición 4 - Mediana diferente de 467

    Conclusión

    Para que la mediana sea 467 , N debe cumplir: 382 < N < 467

    El mayor valor posible para N es ** 466 ** (justo menor que 467 ).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
