Exam 1

  1. Question

    Si la mediana de la asistencia a las 9 salones de un centro de convenciones es 389 y no hay dos salones con el mismo número de participantes, ¿cuál es el mayor valor posible para “N”?


    1. 428
    2. 388
    3. 362
    4. 389

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 389 en un conjunto de 9 valores.

    Datos conocidos:

    • Tenemos 9 salones: D, H, G, I, A, F, E, B, C
    • Sus valores son: 485, 389, 423, N, 339, 539, 497, 330, 364
    • La mediana del conjunto es 389
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 9 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5 ).

    Para que la mediana sea 389 , cuando ordenemos los 9 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 389 .

    Análisis de casos

    Los valores conocidos son: 339, 330, 364, 485, 497, 539, 423, 389

    Analicemos dónde puede ubicarse N para que la mediana sea 389:


    Caso 1: Si N es menor o igual a 330 (muy pequeño) - El valor 389 no quedaría en posición 5 - Mediana diferente de 389

    Caso 2: Si 330 < N < 389 - El valor 389 queda en posición 5 - Mediana = 389 (CORRECTO)

    Caso 3: Si N = 389 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 389 - El valor 389 no estaría en posición 5 - Mediana diferente de 389

    Conclusión

    Para que la mediana sea 389 , N debe cumplir: 330 < N < 389

    El mayor valor posible para N es ** 388 ** (justo menor que 389 ).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
