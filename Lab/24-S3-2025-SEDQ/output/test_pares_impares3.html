Exam 3

  1. Question

    Si la mediana de la asistencia a las 7 atracciones de un parque temático es 375 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 374
    2. 359
    3. 375
    4. 378

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 375 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 atracciones: C, E, F, B, D, A, G
    • Sus valores son: 512, 468, 375, 320, 481, 340, N
    • La mediana del conjunto es 375
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 375 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 375 .

    Análisis de casos

    Los valores conocidos son: 340, 320, 512, 481, 468, 375

    Analicemos dónde puede ubicarse N para que la mediana sea 375:


    Caso 1: Si N es menor o igual a 320 (muy pequeño) - El valor 375 no quedaría en posición 4 - Mediana diferente de 375

    Caso 2: Si 320 < N < 375 - El valor 375 queda en posición 4 - Mediana = 375 (CORRECTO)

    Caso 3: Si N = 375 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 375 - El valor 375 no estaría en posición 4 - Mediana diferente de 375

    Conclusión

    Para que la mediana sea 375 , N debe cumplir: 320 < N < 375

    El mayor valor posible para N es ** 374 ** (justo menor que 375 ).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
