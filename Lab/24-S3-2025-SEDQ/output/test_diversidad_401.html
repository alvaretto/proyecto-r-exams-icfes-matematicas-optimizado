Exam 1

  1. Question

    Si la mediana de la asistencia a las 9 restaurantes de un plaza de comidas es 421 y no hay dos restaurantes con el mismo número de comensales, ¿cuál es el mayor valor posible para “N”?


    1. 450
    2. 393
    3. 420
    4. 463

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 421 en un conjunto de 9 valores.

    Datos conocidos:

    • Tenemos 9 restaurantes: B, G, F, D, A, I, H, E, C
    • Sus valores son: 277, 497, 504, 521, 291, N, 421, 447, 374
    • La mediana del conjunto es 421
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 9 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5 ).

    Para que la mediana sea 421 , cuando ordenemos los 9 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 421 .

    Análisis de casos

    Los valores conocidos son: 291, 277, 374, 521, 447, 504, 497, 421

    Analicemos dónde puede ubicarse N para que la mediana sea 421:


    Caso 1: Si N es menor o igual a 277 (muy pequeño) - El valor 421 no quedaría en posición 5 - Mediana diferente de 421

    Caso 2: Si 277 < N < 421 - El valor 421 queda en posición 5 - Mediana = 421 (CORRECTO)

    Caso 3: Si N = 421 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 421 - El valor 421 no estaría en posición 5 - Mediana diferente de 421

    Conclusión

    Para que la mediana sea 421 , N debe cumplir: 277 < N < 421

    El mayor valor posible para N es ** 420 ** (justo menor que 421 ).
