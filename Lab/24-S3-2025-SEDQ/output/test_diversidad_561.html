Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 378 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 361
    2. 401
    3. 340
    4. 377

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 378 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: D, C, B, E, A
    • Sus valores son: 378, 425, 433, N, 315
    • La mediana del conjunto es 378
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 378 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 378 .

    Análisis de casos

    Los valores conocidos son: 315, 433, 425, 378

    Analicemos dónde puede ubicarse N para que la mediana sea 378:


    Caso 1: Si N es menor o igual a 315 (muy pequeño) - El valor 378 no quedaría en posición 3 - Mediana diferente de 378

    Caso 2: Si 315 < N < 378 - El valor 378 queda en posición 3 - Mediana = 378 (CORRECTO)

    Caso 3: Si N = 378 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 378 - El valor 378 no estaría en posición 3 - Mediana diferente de 378

    Conclusión

    Para que la mediana sea 378 , N debe cumplir: 315 < N < 378

    El mayor valor posible para N es ** 377 ** (justo menor que 378 ).
