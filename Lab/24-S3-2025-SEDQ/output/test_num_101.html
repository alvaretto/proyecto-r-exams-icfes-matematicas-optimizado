Exam 1

  1. Question

    Si la mediana de la asistencia a las 10 canchas de tenis de un complejo deportivo es 433 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 432
    2. 436
    3. 419
    4. 433

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 433 en un conjunto de 10 valores.

    Datos conocidos:

    • Tenemos 10 canchas de tenis: A, E, F, B, D, I, C, H, G, J
    • Sus valores son: 358, 549, 527, 376, 479, 433, 399, 533, 514, N
    • La mediana del conjunto es 433
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 10 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5).

    Para que la mediana sea 433, cuando ordenemos los 10 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 433.

    Análisis de casos

    Los valores conocidos son: 358, 376, 399, 479, 549, 527, 514, 533, 433

    Analicemos dónde puede ubicarse N para que la mediana sea 433:


    Caso 1: Si N es menor o igual a 358 (muy pequeño) - Orden: N, 358, 376, 399, 433, 479, 514, 527, 533, 549 - Mediana = 376 diferente de 433

    Caso 2: Si 358 < N < 433 - El valor 433 queda en posición 5 - Mediana = 433 (CORRECTO)

    Caso 3: Si N = 433 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 433 - El valor 433 no estaría en posición 5 - Mediana diferente de 433

    Conclusión

    Para que la mediana sea 433 , N debe cumplir: 358 < N < 433

    El mayor valor posible para N es 432 (justo menor que 433).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
