Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 restaurantes de un plaza de comidas es 410 y no hay dos restaurantes con el mismo número de comensales, ¿cuál es el mayor valor posible para “N”?


    1. 409
    2. 395
    3. 410
    4. 410

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 410 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 restaurantes: E, F, B, A, D, C, G
    • Sus valores son: 550, 410, 309, 330, 553, 455, N
    • La mediana del conjunto es 410
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4).

    Para que la mediana sea 410, cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 410.

    Análisis de casos

    Los valores conocidos son: 330, 309, 455, 553, 550, 410

    Analicemos dónde puede ubicarse N para que la mediana sea 410:


    Caso 1: Si N es menor o igual a 309 (muy pequeño) - Orden: N, 309, 330, 410, 455, 550, 553 - Mediana = 330 diferente de 410

    Caso 2: Si 309 < N < 410 - El valor 410 queda en posición 4 - Mediana = 410 (CORRECTO)

    Caso 3: Si N = 410 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 410 - El valor 410 no estaría en posición 4 - Mediana diferente de 410

    Conclusión

    Para que la mediana sea 410 , N debe cumplir: 309 < N < 410

    El mayor valor posible para N es 409 (justo menor que 410).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
