Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 auditorios de un centro cultural es 409 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 394
    2. 414
    3. 408
    4. 409

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 409 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 auditorios: A, C, D, B, E
    • Sus valores son: 349, 508, 409, 485, N
    • La mediana del conjunto es 409
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 409 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 409 .

    Análisis de casos

    Los valores conocidos son: 349, 485, 508, 409

    Analicemos dónde puede ubicarse N para que la mediana sea 409:


    Caso 1: Si N es menor o igual a 349 (muy pequeño) - El valor 409 no quedaría en posición 3 - Mediana diferente de 409

    Caso 2: Si 349 < N < 409 - El valor 409 queda en posición 3 - Mediana = 409 (CORRECTO)

    Caso 3: Si N = 409 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 409 - El valor 409 no estaría en posición 3 - Mediana diferente de 409

    Conclusión

    Para que la mediana sea 409 , N debe cumplir: 349 < N < 409

    El mayor valor posible para N es 408 (justo menor que 409).

    2. Falso
    3. Verdadero
    4. Falso
