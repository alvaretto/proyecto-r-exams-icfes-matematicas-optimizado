Exam 1

  1. Question

    Si la mediana de la asistencia a las 9 auditorios de un centro cultural es 439 y no hay dos auditorios con el mismo número de espectadores, ¿cuál es el mayor valor posible para “N”?


    1. 483
    2. 425
    3. 419
    4. 438

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 439 en un conjunto de 9 valores.

    Datos conocidos:

    • Tenemos 9 auditorios: E, I, F, B, G, H, D, A, C
    • Sus valores son: 539, N, 574, 345, 477, 439, 589, 292, 363
    • La mediana del conjunto es 439
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 9 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5 ).

    Para que la mediana sea 439 , cuando ordenemos los 9 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 439 .

    Análisis de casos

    Los valores conocidos son: 292, 345, 363, 589, 539, 574, 477, 439

    Analicemos dónde puede ubicarse N para que la mediana sea 439:


    Caso 1: Si N es menor o igual a 292 (muy pequeño) - El valor 439 no quedaría en posición 5 - Mediana diferente de 439

    Caso 2: Si 292 < N < 439 - El valor 439 queda en posición 5 - Mediana = 439 (CORRECTO)

    Caso 3: Si N = 439 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 439 - El valor 439 no estaría en posición 5 - Mediana diferente de 439

    Conclusión

    Para que la mediana sea 439 , N debe cumplir: 292 < N < 439

    El mayor valor posible para N es ** 438 ** (justo menor que 439 ).
