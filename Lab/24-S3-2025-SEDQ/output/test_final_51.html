Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 canchas de tenis de un complejo deportivo es 392 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 393
    2. 386
    3. 392
    4. 391

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 392 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 canchas de tenis: B, C, A, D, E
    • Sus valores son: 476, 483, 339, 392, N
    • La mediana del conjunto es 392
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 392 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 392 .

    Análisis de casos

    Los valores conocidos son: 339, 476, 483, 392

    Analicemos dónde puede ubicarse N para que la mediana sea 392:


    Caso 1: Si N es menor o igual a 339 (muy pequeño) - El valor 392 no quedaría en posición 3 - Mediana diferente de 392

    Caso 2: Si 339 < N < 392 - El valor 392 queda en posición 3 - Mediana = 392 (CORRECTO)

    Caso 3: Si N = 392 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 392 - El valor 392 no estaría en posición 3 - Mediana diferente de 392

    Conclusión

    Para que la mediana sea 392 , N debe cumplir: 339 < N < 392

    El mayor valor posible para N es 391 (justo menor que 392).


    1. Falso
    2. Falso
    3. Falso
    4. Verdadero
