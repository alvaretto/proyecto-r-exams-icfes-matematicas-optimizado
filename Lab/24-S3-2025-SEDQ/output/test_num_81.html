Exam 1

  1. Question

    Si la mediana de la asistencia a las 10 restaurantes de un plaza de comidas es 462 y no hay dos restaurantes con el mismo número de comensales, ¿cuál es el mayor valor posible para “N”?


    1. 455
    2. 462
    3. 461
    4. 463

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 462 en un conjunto de 10 valores.

    Datos conocidos:

    • Tenemos 10 restaurantes: D, G, B, H, C, A, F, I, E, J
    • Sus valores son: 521, 509, 402, 574, 399, 379, 582, 462, 596, N
    • La mediana del conjunto es 462
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 10 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5).

    Para que la mediana sea 462, cuando ordenemos los 10 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 462.

    Análisis de casos

    Los valores conocidos son: 379, 402, 399, 521, 596, 582, 509, 574, 462

    Analicemos dónde puede ubicarse N para que la mediana sea 462:


    Caso 1: Si N es menor o igual a 379 (muy pequeño) - Orden: N, 379, 399, 402, 462, 509, 521, 574, 582, 596 - Mediana = 399 diferente de 462

    Caso 2: Si 379 < N < 462 - El valor 462 queda en posición 5 - Mediana = 462 (CORRECTO)

    Caso 3: Si N = 462 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 462 - El valor 462 no estaría en posición 5 - Mediana diferente de 462

    Conclusión

    Para que la mediana sea 462 , N debe cumplir: 379 < N < 462

    El mayor valor posible para N es 461 (justo menor que 462).

    2. Falso
