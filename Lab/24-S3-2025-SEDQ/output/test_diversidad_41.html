Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 canchas de tenis de un complejo deportivo es 438 y no hay dos canchas de tenis con el mismo número de jugadores, ¿cuál es el mayor valor posible para “N”?


    1. 482
    2. 426
    3. 437
    4. 394

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 438 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 canchas de tenis: D, A, B, C, E
    • Sus valores son: 438, 356, 461, 563, N
    • La mediana del conjunto es 438
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3 ).

    Para que la mediana sea 438 , cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 438 .

    Análisis de casos

    Los valores conocidos son: 356, 461, 563, 438

    Analicemos dónde puede ubicarse N para que la mediana sea 438:


    Caso 1: Si N es menor o igual a 356 (muy pequeño) - El valor 438 no quedaría en posición 3 - Mediana diferente de 438

    Caso 2: Si 356 < N < 438 - El valor 438 queda en posición 3 - Mediana = 438 (CORRECTO)

    Caso 3: Si N = 438 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 438 - El valor 438 no estaría en posición 3 - Mediana diferente de 438

    Conclusión

    Para que la mediana sea 438 , N debe cumplir: 356 < N < 438

    El mayor valor posible para N es ** 437 ** (justo menor que 438 ).
