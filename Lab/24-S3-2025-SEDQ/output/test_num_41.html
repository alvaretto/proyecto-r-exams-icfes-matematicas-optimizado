Exam 1

  1. Question

    Si la mediana de la asistencia a las 5 atracciones de un parque temático es 349 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 357
    2. 348
    3. 336
    4. 349

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 349 en un conjunto de 5 valores.

    Datos conocidos:

    • Tenemos 5 atracciones: A, D, C, B, E
    • Sus valores son: 218, 349, 437, 428, N
    • La mediana del conjunto es 349
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 5 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 3).

    Para que la mediana sea 349, cuando ordenemos los 5 valores de menor a mayor, el valor en la posición 3 debe ser exactamente 349.

    Análisis de casos

    Los valores conocidos son: 218, 428, 437, 349

    Analicemos dónde puede ubicarse N para que la mediana sea 349:


    Caso 1: Si N es menor o igual a 218 (muy pequeño) - Orden: N, 218, 349, 428, 437 - Mediana = 349 diferente de 349

    Caso 2: Si 218 < N < 349 - El valor 349 queda en posición 3 - Mediana = 349 (CORRECTO)

    Caso 3: Si N = 349 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 349 - El valor 349 no estaría en posición 3 - Mediana diferente de 349

    Conclusión

    Para que la mediana sea 349 , N debe cumplir: 218 < N < 349

    El mayor valor posible para N es 348 (justo menor que 349).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
