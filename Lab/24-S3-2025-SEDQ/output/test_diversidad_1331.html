Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 atracciones de un parque temático es 457 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 456
    2. 428
    3. 411
    4. 457

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 457 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 atracciones: C, E, B, F, D, G, A
    • Sus valores son: 482, 570, 340, 457, 560, N, 308
    • La mediana del conjunto es 457
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 457 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 457 .

    Análisis de casos

    Los valores conocidos son: 308, 340, 482, 560, 570, 457

    Analicemos dónde puede ubicarse N para que la mediana sea 457:


    Caso 1: Si N es menor o igual a 308 (muy pequeño) - El valor 457 no quedaría en posición 4 - Mediana diferente de 457

    Caso 2: Si 308 < N < 457 - El valor 457 queda en posición 4 - Mediana = 457 (CORRECTO)

    Caso 3: Si N = 457 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 457 - El valor 457 no estaría en posición 4 - Mediana diferente de 457

    Conclusión

    Para que la mediana sea 457 , N debe cumplir: 308 < N < 457

    El mayor valor posible para N es ** 456 ** (justo menor que 457 ).


    1. Verdadero
    2. Falso
    3. Falso
    4. Falso
