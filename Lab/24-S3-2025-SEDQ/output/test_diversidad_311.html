Exam 1

  1. Question

    Si la mediana de la asistencia a las 7 atracciones de un parque temático es 382 y no hay dos atracciones con el mismo número de visitantes, ¿cuál es el mayor valor posible para “N”?


    1. 345
    2. 381
    3. 373
    4. 388

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 382 en un conjunto de 7 valores.

    Datos conocidos:

    • Tenemos 7 atracciones: A, F, C, E, G, D, B
    • Sus valores son: 335, 382, 423, 464, N, 491, 299
    • La mediana del conjunto es 382
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 7 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 4 ).

    Para que la mediana sea 382 , cuando ordenemos los 7 valores de menor a mayor, el valor en la posición 4 debe ser exactamente 382 .

    Análisis de casos

    Los valores conocidos son: 335, 299, 423, 491, 464, 382

    Analicemos dónde puede ubicarse N para que la mediana sea 382:


    Caso 1: Si N es menor o igual a 299 (muy pequeño) - El valor 382 no quedaría en posición 4 - Mediana diferente de 382

    Caso 2: Si 299 < N < 382 - El valor 382 queda en posición 4 - Mediana = 382 (CORRECTO)

    Caso 3: Si N = 382 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 382 - El valor 382 no estaría en posición 4 - Mediana diferente de 382

    Conclusión

    Para que la mediana sea 382 , N debe cumplir: 299 < N < 382

    El mayor valor posible para N es ** 381 ** (justo menor que 382 ).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
