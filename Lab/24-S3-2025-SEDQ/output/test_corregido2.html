Exam 2

  1. Question

    Si la mediana de la asistencia a las 9 salas de cine de un centro comercial es 422 y no hay dos salas de cine con el mismo número de asistentes, ¿cuál es el mayor valor posible para “N”?


    1. 408
    2. 421
    3. 422
    4. 430

    Solution

    Análisis del problema

    Para resolver este problema, necesitamos entender qué significa que la mediana sea 422 en un conjunto de 9 valores.

    Datos conocidos:

    • Tenemos 9 salas de cine: G, C, F, H, D, A, B, E, I
    • Sus valores son: 516, 400, 557, 422, 455, 301, 367, 478, N
    • La mediana del conjunto es 422
    • No hay dos valores iguales

    Concepto de mediana

    La mediana de 9 valores ordenados de menor a mayor es el valor que ocupa la posición central (posición 5 ).

    Para que la mediana sea 422 , cuando ordenemos los 9 valores de menor a mayor, el valor en la posición 5 debe ser exactamente 422 .

    Análisis de casos

    Los valores conocidos son: 301, 367, 400, 455, 478, 557, 516, 422

    Analicemos dónde puede ubicarse N para que la mediana sea 422:


    Caso 1: Si N es menor o igual a 301 (muy pequeño) - El valor 422 no quedaría en posición 5 - Mediana diferente de 422

    Caso 2: Si 301 < N < 422 - El valor 422 queda en posición 5 - Mediana = 422 (CORRECTO)

    Caso 3: Si N = 422 - No es válido porque no puede haber valores iguales

    Caso 4: Si N > 422 - El valor 422 no estaría en posición 5 - Mediana diferente de 422

    Conclusión

    Para que la mediana sea 422 , N debe cumplir: 301 < N < 422

    El mayor valor posible para N es 421 (justo menor que 422).


    1. Falso
    2. Verdadero
    3. Falso
    4. Falso
