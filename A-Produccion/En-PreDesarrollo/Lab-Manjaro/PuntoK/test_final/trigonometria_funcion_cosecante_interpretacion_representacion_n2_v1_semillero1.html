Exam 1

  1. Question

    Un punto K se mueve de un extremo a otro del segmento QT que se muestra en la gráfica.

    El ángulo α\alpha y la medida h se relacionan mediante la razón trigonométrica sen(α\alpha) = hKP\frac{h}{KP}, de donde se deduce la distancia entre K y P como KP = hsen(α)\frac{h}{\text{sen}(\alpha)} o KP = h ×\times csc(α\alpha).

    ¿Cuál es la gráfica que muestra las distancias KP, cada vez que K se mueve sobre el segmento QT?


    Solution

    Para resolver este problema, debemos analizar la función KP = h/sen(α\alpha).

    Análisis matemático:

    La función KP = h/sen(α\alpha) = h ⋅\cdot csc(α\alpha) es la función cosecante multiplicada por la constante h.

    Características de la función cosecante:

    1. Dominio: α∈(0°,90°)\alpha \in (0°, 90°) en este contexto geométrico
    2. Comportamiento:
      • Cuando α→0°\alpha \to 0°: sen(α\alpha) →0\to 0, por lo tanto KP →∞\to \infty
      • Cuando α→90°\alpha \to 90°: sen(α\alpha) →1\to 1, por lo tanto KP →h\to h
      • La función es estrictamente decreciente en el intervalo (0°, 90°)

    Verificación con valores específicos:

    • Para α\alpha = 30°: KP = h/sen(30°) = h/0.5 = 2h = 6
    • Para α\alpha = 45°: KP = h/sen(45°) = h/(2\sqrt{2}/2) ≈\approx 1.41h ≈\approx 4.2
    • Para α\alpha = 60°: KP = h/sen(60°) = h/(3\sqrt{3}/2) ≈\approx 1.15h ≈\approx 3.4

    La gráfica correcta debe mostrar: - Una curva que decrece de manera no lineal - Valores muy altos cuando α\alpha se acerca a 0° - Un valor mínimo de h cuando α\alpha se acerca a 90° - Forma característica de la función cosecante

    Análisis de las opciones:- Opción A : Muestra una función constante - Incorrecta- Opción B : Muestra una función lineal - Incorrecta- Opción C : Muestra una función cuadrática - Incorrecta- Opción D : Muestra la función cosecante KP = h/sen(α\alpha) - CORRECTARespuesta correcta: Opción A
