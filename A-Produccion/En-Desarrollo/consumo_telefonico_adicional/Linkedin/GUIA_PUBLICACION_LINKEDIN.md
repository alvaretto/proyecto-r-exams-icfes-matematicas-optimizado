### Fragmentos de Código para Compartir

**Snippet 1: Generación de Gráficos con Python**

```python
# Generación dinámica de gráficos con matplotlib
import matplotlib.pyplot as plt
import numpy as np

# Datos aleatorios de consumo telefónico
meses = ['Sep', 'Oct', 'Nov', 'Dic', 'Ene']
consumo = [245, 312, 289, 267, 398]  # Valores únicos por versión

# Crear gráfico profesional
fig, ax = plt.subplots(figsize=(8, 5))
bars = ax.bar(meses, consumo, color='steelblue', edgecolor='navy')
ax.axhline(y=300, color='red', linestyle='--', label='Plan: 300 min')
ax.set_ylabel('Minutos', fontweight='bold')
ax.set_title('Consumo de Voz - Últimos 5 Meses')
plt.savefig('grafico_consumo.png', dpi=150)
```

**Snippet 2: Generación de Múltiples Versiones**
```r
# Generar 10 versiones únicas del ejercicio
library(exams)

exams2webquiz("consumo_telefonico_adicional_n2_v1.Rmd",
              n = 10,  # 10 versiones diferentes
              dir = "Salida",
              name = "ejercicio_interactivo",
              solution = TRUE,
              shuffle = TRUE,
              mathjax = TRUE)

# Resultado: 10 archivos HTML independientes
# Cada uno con datos, gráficos y opciones únicas
```

**Snippet 3: Compatibilidad Multi-formato**
```r
# Mismo ejercicio → Múltiples formatos

# 1. HTML interactivo (autoevaluación)
exams2webquiz("ejercicio.Rmd", n = 5)

# 2. PDF para imprimir
exams2pdf("ejercicio.Rmd", n = 30)

# 3. Moodle XML (LMS)
exams2moodle("ejercicio.Rmd", n = 100)

# 4. Examen escaneable (NOPS)
exams2nops("ejercicio.Rmd", n = 50)
```
