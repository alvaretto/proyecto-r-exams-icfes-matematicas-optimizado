- **contexto**: consumo_telefonico
- **contenido**: adicional (tiempo adicional consumido)
- **componente**: implícito (numérico-variacional)
- **nivel**: n2 (Nivel 2: 36-50 puntos)
- **version**: v1 (primera versión aprobada)
